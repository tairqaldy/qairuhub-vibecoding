<Lead>
You build the same small thing twice, maybe three times. Explore, plan, approve, review, commit works the same in every tool. Only the shortcut changes.
</Lead>

Five tools changed owner, price or name in the last year ([module 07](/en/learn/the-agent/) has the list). If your skill is knowing where the buttons are, one product decision deletes it. The loop and one instructions file move with you.

## One folder, one commit, one task

<Terminal title="bash">
```bash
mkdir vibe-demo
cd vibe-demo
git init
git commit --allow-empty -m "empty start"
```
</Terminal>

The task, in every tool: a single-page tenge/USD converter with a hardcoded rate, plain HTML/CSS/JS, no build step. Five minutes of work; a bad plan still shows.

<Callout type="warn" title="The rule for this whole lab">
Commit before every big prompt. Three agents in one folder in one afternoon is how you lose work you liked. `git` is the only undo button all of them share ([module 09](/en/learn/git-and-github/)).
</Callout>

## Cursor: the plan step is a keyboard shortcut

A VS Code fork with the agent inside, SpaceX-owned [since 14 August 2026](https://cursor.com/blog). Hobby needs no card; [Cursor's own pricing docs](https://cursor.com/docs/account/pricing) put daily agent users at $60–$100 a month on top of the $20 Pro plan. The [pricing page](https://cursor.com/pricing) now lists Grok next to Claude and GPT.

<Steps>
<Step title="Install and open the folder">
Download from [cursor.com](https://cursor.com), sign in with Google or GitHub, then File → Open Folder → `vibe-demo`.
</Step>

<Step title="Open the agent and switch it to Plan mode">
`Ctrl+I` (`Cmd+I` on macOS) opens the agent. In the input, `Shift+Tab` switches to Plan mode — the same idea as in Claude Code ([module 07](/en/learn/the-agent/)). It writes a plan, not files.

<Prompt title="Plan prompt" where="Cursor · agent input, Plan mode (Shift+Tab)">
```text
Plan a single-page tenge/USD converter with a hardcoded rate,
plain HTML/CSS/JS, no build step, one file.

Ask me questions first if anything is ambiguous.
Do not write code yet.
```
</Prompt>

Edit the plan before you approve it. Three lines of plan beat three hundred lines of diff.
</Step>

<Step title="Approve, then review the diff file by file">
Cursor shows each changed file with Accept and Reject. Reject once on purpose, so you know where the button is. Then open `index.html` yourself.
</Step>

<Step title="Make it write the instructions file, then commit">
Ask: "create an AGENTS.md with how to run this project and the code style we just used". Then `git add -A && git commit -m "first agent build"`.
</Step>

<Step title="Optional: the same agent in your terminal">
Cursor ships a CLI; the binary is `agent`. Install with `curl https://cursor.com/install -fsS | bash` (macOS, Linux, WSL) or `irm 'https://cursor.com/install?win32=true' | iex` in PowerShell, then run `agent "explain this repo"`.
</Step>
</Steps>

<Callout type="info" title="If you came for the free student year">
It is gone. Cursor's [students page](https://cursor.com/students) now promises only promotions at campus and online events. Plan on Hobby, or a free option below.
</Callout>

## Codex CLI: the plan step is something you ask for

OpenAI's agent, one account across terminal, IDE extension and cloud. The CLI is [Apache-2.0, 125.7k stars](https://github.com/openai/codex) on 21 September 2026. The plans are in [module 07](/en/learn/the-agent/); what matters here is that the published [limits](https://learn.chatgpt.com/docs/pricing) are ranges per five hours that move with the model, not one number.

<Steps>
<Step title="Install it">
<Terminal title="bash">
```bash
# macOS / Linux
npm install -g @openai/codex
# or
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Terminal>

<Terminal title="PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Terminal>

The package is `@openai/codex`, not `codex`. Copy that line, do not type it from memory.
</Step>

<Step title="Sign in, then look at the dials before you prompt">
Run `cd vibe-demo && codex` and choose "Sign in with ChatGPT". Then three slash commands, in order. `/status` shows model, sandbox and approval setting. `/model` picks model and reasoning effort. `/permissions` decides what runs without asking. On Windows a [secondary guide](https://www.codeagentswarm.com/en/guides/codex-cli-on-windows) calls the sandbox experimental — prefer WSL, keep approvals on.
</Step>

<Step title="Let it write AGENTS.md, then cut it down">
`/init` writes an `AGENTS.md`. Open it and delete every line that is obvious or untrue.
</Step>

<Step title="Build the same converter">
<Prompt title="Build prompt" where="Codex CLI · after /init">
```text
Build the tenge/USD converter described in AGENTS.md:
one HTML file, hardcoded rate, no build step.

Show me the plan first and wait for my yes.
Then make the edits one at a time.
```
</Prompt>

Approve each edit and command as it appears. Open the page yourself; a summary is not evidence.
</Step>

<Step title="Make it review its own diff, then scale it">
`/review` makes Codex review your uncommitted changes. Fix what it finds, commit. Three commands for later: `codex exec "add a EUR option"` runs non-interactively, `codex resume` reopens an old session, `codex cloud` hands the task to a machine that is not yours.
</Step>
</Steps>

<Callout type="warn" title="Check this before you promise anyone a free account">
The Codex README's sign-in paragraph names Plus, Pro, Business, Edu and Enterprise; the [pricing page](https://learn.chatgpt.com/docs/pricing) says Free and Go include Codex. Two official pages, two stories. Test with a real free account before you build a workshop on it.
</Callout>

## Gemini CLI is not the free option any more

On 19 May 2026 the maintainers announced that from 18 June, "Gemini CLI will stop serving requests for Google AI Pro and Ultra" — free users included. The post drew [301 thumbs-down against 6 thumbs-up](https://github.com/google-gemini/gemini-cli/discussions/27274). It was the second cut: an [update](https://github.com/google-gemini/gemini-cli/discussions/22970) posted 18 March 2026 had already put Gemini Pro models behind paid subscriptions.

It is still Apache-2.0 and still installs with `npm install -g @google/gemini-cli`. It stays the right tool **if your university or employer has Gemini Code Assist Standard or Enterprise, or you hold a paid key**: run `gemini`, pick API key or Vertex auth, keep context in `GEMINI.md`. Google's pages contradict each other on unpaid AI Studio keys, so test yours the day before you need it.

<Callout type="danger" title="A README is not documentation">
The Gemini CLI README still advertises 1,000 free requests a day, months after the [docs site](https://geminicli.com/docs/resources/quota-and-pricing/) says the tool was replaced for consumers on 18 June 2026. When a README and a docs page disagree, believe the one with a date on it.
</Callout>

### The free terminal agent that took its place

Antigravity CLI is the replacement. Its binary is `agy`. The Individual plan is $0 with weekly rate limits, and it serves non-Google models too: the [pricing page](https://antigravity.google/pricing) lists Gemini 3.8, 3.7 and 3.6 Flash, Gemini 3.1 Pro, Claude Sonnet and Opus 4.6, and gpt-oss-120b. Kazakhstan is on the [supported list](https://antigravity.google/docs/faq/). Two hard limits: personal Google accounts only, nobody under 18.

<Steps>
<Step title="Install and launch">
<Terminal title="PowerShell">
```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```
</Terminal>

<Terminal title="bash">
```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
cd vibe-demo
agy
```
</Terminal>

The binary lands in `~/.local/bin/agy`, or `C:\Users\<username>\AppData\Local\agy\bin` on Windows. Open a new terminal so the path is picked up.
</Step>

<Step title="Get through the first-run wizard">
Colour scheme, rendering mode, trust this workspace, then Google sign-in. On university Wi-Fi the localhost callback sometimes fails. `agy` can print an authorization URL instead.
</Step>

<Step title="Look at your quota before you spend it">
`/usage` shows what is left per model this week. Do this first on any metered tool.
</Step>

<Step title="Make it interrogate you, then build">
`/grill-me` makes the agent ask clarifying questions before it writes anything.

<Prompt title="Grill prompt" where="Antigravity CLI · agy">
```text
/grill-me Build a single-page tenge/USD converter with a hardcoded rate,
plain HTML/CSS/JS, no build step, one file.

Ask me every question you need before you write any code.
```
</Prompt>

Answer honestly, let it build, then open the file yourself.
</Step>

<Step title="Feel the autonomy dial, then commit">
`/goal <task>` runs to the end with no approval stops. Try it on one tiny follow-up, then ask where that setting stops being safe. `agy` reads `AGENTS.md` from the working directory. Antigravity-only rules go in `.agents/rules/`.
</Step>
</Steps>

## The same task, five tools, five kinds of friction

| Tool | Where the plan step lives | What you approve | What $0 gets you |
|---|---|---|---|
| **Claude Code** | `Shift+Tab` into plan mode | the plan, then edits by permission mode | no $0 route here; this course assumes Claude Pro |
| **Cursor** | `Shift+Tab` in the agent input | Accept/Reject per file diff, in a GUI | Hobby, limited agent requests, no card |
| **Codex CLI** | you ask for it in the prompt; `/permissions` sets the rest | each edit and command as it appears | a small allowance inside ChatGPT Free |
| **Gemini CLI** | the same terminal flow as before | only on an enterprise licence or a paid key | nothing for consumers since 18 Jun 2026 |
| **Antigravity `agy`** | `/grill-me` to be questioned; `/goal` to remove the stops | step by step, unless you chose `/goal` | Individual plan, weekly limits, **18+ only** |

A GUI diff is easy to skim and easy to fake-read; a terminal agent shows one edit at a time. Know which one you are more likely to lie to yourself in.

<Deeper title="Money and cards from Kazakhstan">
Kazakhstan is on Anthropic's, OpenAI's and Antigravity's supported lists, so the main tools need no VPN. Kazakhstani Visa and Mastercard cards are [reported to work](https://habr.com/ru/articles/1037638/). The usual failures: foreign payments switched off in the bank app, a 3-D Secure failure, or a billing country that does not match the card.

The three free accounts this lab needs are listed with their limits in [module 07](/en/learn/the-agent/). One of them pays extra: GitHub with an Education application in gives you Copilot Student and 200 AI credits a month.
</Deeper>

## One instructions file that all of them read

`AGENTS.md` at the repo root is the shared standard — what goes inside it is [module 06](/en/learn/context-ssot/). What changes from tool to tool is who reads it, and what else they read.

| File | Who reads it | The detail that catches people |
|---|---|---|
| `AGENTS.md` | Codex, Cursor, Copilot, Jules, opencode, Devin, Aider, `agy`, and Claude Code since 18 Sep 2026 | nested files merge nearest-first, so a package-level file wins |
| `CLAUDE.md` | Claude Code; also VS Code Copilot, where `chat.useClaudeMdFile` is on by default | Claude reads `AGENTS.md` **only** when no CLAUDE.md exists |
| `.cursor/rules/*.mdc` | Cursor only | frontmatter `description`, `globs`, `alwaysApply` — for glob-scoped rules, not shared facts |
| `.github/copilot-instructions.md` | Copilot chat, review and agents | VS Code merges every instruction file it finds, in no guaranteed order |
| `.agents/rules/` | Antigravity IDE, desktop and `agy` | `agy` also still reads `GEMINI.md` |

Shared facts go in `AGENTS.md`, and the prompt below is the shape. For Claude Code, cut `CLAUDE.md` down to `@AGENTS.md` plus Claude-only notes. [Anthropic's docs](https://code.claude.com/docs/en/memory) prefer that import to a symlink, which on Windows needs admin or Developer Mode and can land in git as plain text. Then stop. Copy the same text into `.github/copilot-instructions.md` and VS Code merges both, so you pay for those tokens twice.

Keep it short and non-obvious, like any context file ([module 06](/en/learn/context-ssot/)). ETH Zurich and LogicStar.ai found context files did not generally improve task success while adding over 20% to inference cost — repository overviews least of all, though written instructions were followed well. [Vercel's counter-example](https://vercel.com/blog/agents-md-outperforms-skills-in-our-agent-evals) points the same way: an 8 KB compressed docs index in `AGENTS.md` took their Next.js evals from 53% to 100%.

<Prompt title="Write the file that earns its tokens" where="Any agent · in your repo, after the first build">
```text
Write an AGENTS.md for this repo. Hard limit: 30 lines.

Include ONLY what you could not guess by reading the code:
- the exact commands to install, run, test and lint
- anything that breaks if done the obvious way
- files or folders you must not edit
- our commit message convention

Do not describe the folder structure.
Do not summarise what the code does.
If you are unsure about a command, ask me instead of guessing.
```
</Prompt>

## Keep the habit, drop the tool

<Callout type="danger" title="A sandbox is not permission to stop looking">
In July 2026 Pillar Security demonstrated [sandbox escapes](https://www.bleepingcomputer.com/news/security/cursor-codex-gemini-cli-antigravity-hit-by-sandbox-escapes/) in all four tools on this page, triggered by prompt injection hidden in READMEs and dependencies ([module 11](/en/learn/security/)). The agent stayed sandboxed; trusted tools outside it later ran the files it wrote. Cursor fixed it in 3.0.0 (CVE-2026-48124), Codex CLI in v0.95.0. Text inside a repo you cloned is untrusted data, never instructions, and auto-approve belongs nowhere near it.
</Callout>

    'Check the usage meter after your first real task, before trusting a free tier',

    'Check the docs page, not the README, before believing a free tier still exists',
