Бұл практикада ақылды ештеңе жоқ. Бұл — алдағы үш сағат бағдарлама жасауға кете ме, әлде *неге ештеңе жұмыс істемейтінін* іздеуге кете ме, соны шешетін жиырма минут.

Әр қадам бірдеңе басып шығаратын пәрменмен аяқталады. Басып шығарса — орнату шын. Басып шығармаса, шешімі осы бетте тұр.

## Үш орнату, бір аккаунт — ал агент бұл тізімде жоқ

Сен **Node**, **git** және **VS Code** орнатасың әрі **GitHub аккаунтын** ашасың. Бүкіл құрал-сайманың — осы. Агент [01-практикада](/kk/labs/claude-code-first-session/) келеді, мұнда ол әдейі жоқ.

Claude Code-тың меншікті орнатушысына әкімші құқығы да, WSL де, Node.js та қажет емес — 4 ГБ жады бар Windows 10 1809 немесе одан жаңа нұсқа жетеді ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)). Тіпті Code қойындысы терминалсыз ашылатын жұмыс үстелі қолданбасы да бар ([жұмыс үстелі нұсқаулығы](https://code.claude.com/docs/en/desktop-quickstart)).

Демек бұл орнатулар агент үшін емес, сенің жобаң үшін. Курс бойы жасайтын QAIRU Event Sign-up қолданбасына іске қосылу үшін Node, не өзгергенін есте сақтау үшін git және агент не жазғанын оқу үшін редактор керек.

## Терминал қай жерде тұрады және сенде қайсысы бар

Терминал — пәрмен орындайтын терезе. Ең алдымен соны ашып ал.

- **Windows** — Start түймесін басып, `terminal` деп тер де, Windows Terminal-ды аш. Ол жоқ па? `powershell` деп тер, не болмаса `winget install Microsoft.WindowsTerminal` пәрменімен орнат. Ол тегін әрі ашық бастапқы кодты ([microsoft/terminal](https://github.com/microsoft/terminal)). Кейінірек оның бөлінетін панельдері керек болады: `Alt+Shift+D` агентті сол жаққа, журналдарды оң жаққа қояды.
- **macOS** — `Cmd+Space` басып, `terminal` деп теріп, Enter пернесін бас.
- **Linux** — көп ортада `Ctrl+Alt+T`.

Енді курсор тұрған жолды оқып шық. Windows-та ол қай shell-де тұрғаныңды айтады. Пәрменді басқа shell-ге қойсаң, Anthropic құжаттамасында тізілген екі қатенің бірін аласың ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)).

| Жол мынаған ұқсаса | Сен тұрған жер | Демек |
|---|---|---|
| `PS C:\Users\you>` | PowerShell | «PowerShell үшін» деп жазылған пәрмендер осында |
| `C:\Users\you>` | CMD | «CMD үшін» деп жазылған пәрмендер осында |
| `you@laptop:~$` | Git Bash, WSL, macOS немесе Linux | кез келген оқулықтағы macOS/Linux жолы сол күйінде жұмыс істейді |

## Орнат, содан соң дәлелде

<Steps>

<Step title="Node орнат — npm онымен бірге келеді">
Node.js-тің ресми жүктеп алу бетінен операциялық жүйеңе арналған **LTS** нұсқасын ал: Windows-та `.msi` орнатушысы, macOS-та `.pkg` орнатушысы, Linux-та сол бет өз дистрибутивіңе беретін нұсқау. Әдепкі параметрлерді өзгертпе.

LTS — long-term support, яғни ұзақ мерзімді қолдау: ең қызықсыз нұсқа, ал саған дәл сол керек. 20-нұсқадан жоғарысының бәрі жарайды. Сонда да ең жаңа LTS-ті ал: Claude Code-ты меншікті орнатушысының орнына npm арқылы орнатсаң, ол жол Node.js 22 немесе одан жаңасын сұрайды ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)).

Содан соң **ашық тұрған терминалды жауып, жаңасын аш.** Терминал өзі ашылған сәттегі ортаны сақтап қалады да, оны орнатушының өзгерткенін байқамайды. Жаңа орнатылған бағдарламаның бұзылған болып көрінуінің ең жиі себебі — осы.

<Terminal title="тексеру" copy={false}>

```text
> node -v
v22.20.0

> npm -v
10.9.3
```

</Terminal>

Сенде сандар басқаша, әрі жоғарырақ болады. Маңыздысы — пішіні: `node -v` жауабы `v` әрпі мен цифрлардан тұрады, ал `npm -v` жауабы — цифрлар. npm Node-пен бірге келеді, оны бөлек орнатпайсың.
</Step>

<Step title="git орнат">
**Windows:** [Git for Windows](https://git-scm.com/downloads/win) жүктеп алып, іске қос. Әдепкі параметрлерді қалдыр. Anthropic құжаттамасы мұны Claude Code үшін міндетті емес дейді де, сонда да орнатуға кеңес береді: Git for Windows тұрса, Claude Code өзінің Bash құралы үшін Git Bash-ті пайдаланады; ол болмаса, PowerShell құралына ауысады ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)). git саған 02-практикадан бастап бәрібір керек.

**macOS:** `git --version` пәрменін орында. git жоқ болса, macOS әзірлеушіге арналған пәрмен жолы құралдарын ұсынады — келіс, күте тұр да, пәрменді қайта орында.

**Linux (Debian/Ubuntu):** `sudo apt install git`.

<Terminal title="тексеру" copy={false}>

```text
> git --version
git version 2.51.0
```

</Terminal>

Мұнда да нақты нөмірдің маңызы жоқ. `git version` деген сөздер және олардан кейінгі цифрлар — бар маңыздысы сол.
</Step>

<Step title="VS Code орнат және онымен қалта аш">
VS Code — тегін редактор, оның өзегі ашық бастапқы кодты ([microsoft/vscode](https://github.com/microsoft/vscode)). Microsoft сайтынан өз жүйеңе арналған нұсқасын жүктеп алып орнат, не болмаса Windows-та `winget install Microsoft.VisualStudioCode` пәрменін орында.

Содан кейін ең маңызды жалғыз істі орында: **File → Open Folder** дегенді басып, қалта таңда. Файлды емес — қалтаны. Осы курстағы бәрі де, агенттің кез келген әрекеті де бір қалтаның шегінде жүреді.

<Callout type="warn" title="Кеңейтім деген — пәрмен емес">
Кейінірек Claude Code кеңейтімін қосуың мүмкін: Extensions панелі (`Ctrl+Shift+X`), «Claude Code» деп ізде, содан соң Command Palette (`Ctrl+Shift+P`) → «Claude Code» → Open in New Tab. Мынаны алдын ала біліп қой: кеңейтім CLI құралының өз жеке көшірмесін ала келеді және `claude` пәрменін PATH-қа **қоспайды** ([VS Code интеграциясы](https://code.claude.com/docs/en/vs-code)). Адамдар оны орнатып алып, терминалда `claude` деп тереді, "not recognized" деген жауап алады да, орнату сәтсіз болды деп ойлайды. Олай емес. Бұл — екі бөлек орнату.
</Callout>
</Step>

<Step title="Курстың соңына дейін өмір сүретін қалтаңды жаса">
Бір жоба — бір қалта. Жұмыс үстелі емес, үй каталогы емес — аты бар бөлек қалта.

<Terminal title="powershell">

```powershell
cd $HOME\Documents
mkdir qairu-event
cd qairu-event
```

</Terminal>

<Terminal title="bash">

```bash
cd ~/Documents
mkdir qairu-event
cd qairu-event
```

</Terminal>

Осы жолдарды бір қатарға біріктірсең, бөлгіші басқа: PowerShell-де `;`, Bash-те `&&`. Келесі бөлімдегі екі қате хабары осы айырмашылықтан шығады.

Агентті үй қалтаңда немесе жұмыс үстелінде іске қоссаң, өзіңдегі барлық файлды оқуға және индекстеуге бергенің. Алдымен `cd` арқылы жоба қалтасына кір — әр жолы.
</Step>

<Step title="Бәрін бір жаңа терминалда дәлелде">
Барлық орнатудан **кейін** ашылған терминалда, `qairu-event` қалтасының ішінде тұрып:

<Terminal title="тексеру">

```bash
node -v
git --version
```

</Terminal>

Екі нұсқа нөмірі, қатесіз. Содан соң осы қалтаны VS Code-та аш — File → Open Folder арқылы, немесе орнатушы `code` пәрменін қосқан болса, `code .` деп тер — және сол жақта (бос) файлдар ағашын көріп тұрғаныңа көз жеткіз.

Дайын болу деген — екі сан және бір қалта.
</Step>

</Steps>

## Windows қарсыласа

Бұл залдағылардың басым бөлігі Windows-та отыр, ал оқулықтардың көбін Windows-та отырмайтындар жазады. Пәрменді қайта-қайта орындағанша, хабарды оқып шық. Төмендегі әр жол Anthropic-тің [орнату](https://code.claude.com/docs/en/setup) және [орнату ақауларын жою](https://code.claude.com/docs/en/troubleshoot-install) беттерінен алынған, әрі Claude Code шеңберінен әлдеқайда кең қолданылады.

| Хабар | Шын мәнінде не болды | Шешімі |
|---|---|---|
| `'x' is not recognized` | ол қалта PATH-та жоқ — немесе терминал орнатудан бұрын ашылған | алдымен **жаңа** терминал аш; сонда да болмаса, қалта шынымен PATH-та жоқ |
| `The token '&&' is not a valid statement separator` | CMD пәрмені PowerShell-ге қойылған | пәрмендердің арасына `;` қой немесе shell ауыстыр |
| `'irm' is not recognized` | PowerShell пәрмені CMD-ге қойылған | PowerShell ашып, сол жерде орында |
| `running scripts is disabled on this system` | PowerShell-дің орындау саясаты скрипт қабықшасын бұғаттап тұр; құжаттамада дәл осы қате npm қабықшалары үшін көрсетілген | сол пәрменді CMD-де немесе Git Bash-те орында — онда PowerShell саясаты жүрмейді |
| `Claude Code does not support 32-bit Windows` | «PowerShell (x86)» ашылған | оны жауып, кәдімгі PowerShell немесе Windows Terminal аш |
| `syntax error near unexpected token '<'` немесе curl 403 қайтарса | орнату скрипті HTML бет қайтарған — желі немесе аймақ бойынша бұғаттау | басқа желіні байқап көр; Қазақстанның өзіне қолдау бар, төменде қара |

<Callout type="tip" title="PATH ережесі, бір жолда">
PATH — терминал бағдарламаларды іздейтін қалталар тізімі. Орнатушы оған жаңа жол қоса алады, ал ашық тұрған терминал оны қайта оқымайды. Сондықтан «орнаттым, бірақ not recognized дейді» дегеннің шешімі мынау: терезені жап, жаңасын аш, пәрменді қайта орында.
</Callout>

## Бүгін кешке ашып қоятын аккаунттар

Төртеуі де тегін. Бірде-бірі банк картасын сұрамайды.

| Аккаунт | Қайда | Не үшін керек |
|---|---|---|
| GitHub | [github.com](https://github.com) | кодыңның үйі әрі 02-практикадан бастап ашық портфолиоң |
| GitHub Education | [education.github.com/pack](https://education.github.com/pack) | университет поштаң болса: Copilot Student, Pro деңгейіндегі Codespaces (айына 180 сағат есептеу) және Namecheap, .TECH не Name.com-нан тегін домен |
| Claude | [claude.ai](https://claude.ai) | курсты браузерде қадағалап отыруға тегін аккаунт жетеді; Claude Code-тың өзіне ақылы тариф керек, төменде қара |
| Қосымша Google аккаунты және тегін ChatGPT аккаунты | — | тегін агенттер солардың артында тұр: Antigravity-дің Individual тарифі — $0 ([бағалар](https://antigravity.google/pricing), өзінің [жиі қойылатын сұрақтарына](https://antigravity.google/docs/faq/) сәйкес тек 18+) және Codex — ол шағын лимитпен тегін ChatGPT деңгейіне кіреді ([тарифтер](https://learn.chatgpt.com/docs/pricing)) |

Қазақстан Anthropic-тің қолдау көрсетілетін елдер тізімінде тұр — Claude.ai бойынша да, API бойынша да ([қолдау көрсетілетін елдер](https://www.anthropic.com/supported-countries)), сондықтан VPN қажет емес. Бірақ тегін Claude тарифіне Claude Code **кірмейді** — оған Pro, Max, Team, Enterprise немесе Console төлемі керек ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)). Pro — айына $20, жылдық төлеммен айына $17 ([бағалар](https://claude.com/pricing)). Осы шеберлік сабағына бір ай жетеді.

Ал «студенттік тариф» дегеніміз «сол өнімнің өзі, бірақ тегін» емес. GitHub пакеті Copilot Pro емес, Copilot Student береді. Студенттер GPT-5.3-Codex, GPT-5.4, Claude Opus немесе Claude Sonnet модельдерін қолмен таңдай алмайды — оларға тек Auto режимі арқылы жетеді — ал лимит айына 200 ЖИ-кредит, бір кредит — бір цент қолданыс. Жарияланымға 6 796 «ұнатпадым» реакциясы жиналды ([GitHub қауымдастығындағы талқылау](https://github.com/orgs/community/discussions/189268), [Copilot тарифтері](https://github.com/features/copilot/plans)). Тегін — әлі де тегін, тек жарнама меңзегеннен кішірек.

<Deeper title="Тегін орналастыру тарифтері: қайсысын қазір ашу керек, қайсысынан аулақ жүрген жөн">
Сен [12-модульде](/kk/learn/deploy/) deploy жасайсың. Түн ортасында баға беттерін оқығанша, керекті аккаунтты қазір ашып қой.

- **Cloudflare Pages** — мұндағы қауіпсіз әдепкі таңдау. Тегін тариф: айына 500 build, 100 жоба және статикалық файлдар үшін көрсетілген трафик шегі жоқ ([шектеулер](https://developers.cloudflare.com/pages/platform/limits/)).
- **Vercel Hobby** — жомарт, бірақ **тек коммерциялық емес, жеке қолданысқа**, ал шектен шықсаң, әдетте 30 күн күтуге тура келеді ([Hobby тарифі](https://vercel.com/docs/plans/hobby)).
- **Netlify Free** — айына 300 кредит, қатаң шек, келесі айға ауыспайды, ал жұмыс ортасына бір deploy 15 кредит тұрады. Жиырма deploy бүкіл айды бітіреді, одан кейін жобаларың келесі кезеңге дейін тоқтатылады ([кредиттік баға](https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/credit-based-pricing-plans/)). Жиі deploy жасайтын курсқа бұл — қолайсыз таңдау.
