## Үш орнату, бір аккаунт — ал агент бұл тізімде жоқ

Сен **Node**, **git** және **VS Code** орнатасың әрі **GitHub аккаунтын** ашасың. Агент [01-практикада](/kk/labs/claude-code-first-session/) келеді, мұнда ол әдейі жоқ.

Агентке бұлардың бірі де керек емес: Claude Code-тың орнатушысы әкімші құқығын да, WSL-ді де, Node.js-ті де сұрамайды — 4 ГБ жады бар Windows 10 1809 немесе одан жаңа нұсқа жетеді ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)). Оның жұмыс үстелі қолданбасына терминал да керек емес ([жұмыс үстелі нұсқаулығы](https://code.claude.com/docs/en/desktop-quickstart)).

Бұл орнатулар сенің жобаң үшін. Курс бойы жасайтын QAIRU Event Sign-up қолданбасына іске қосылу үшін Node, не өзгергенін есте сақтау үшін git, агент не жазғанын оқу үшін редактор керек.

## Терминал қай жерде тұрады және сенде қайсысы бар

Терминал — пәрмен орындайтын терезе. Ең алдымен соны ашып ал.

- **Windows** — Start түймесін басып, `terminal` деп тер де, Windows Terminal-ды аш. Ол жоқ па? `powershell` деп тер, не `winget install Microsoft.WindowsTerminal` пәрменімен орнат — ол тегін әрі ашық бастапқы кодты ([microsoft/terminal](https://github.com/microsoft/terminal)). Кейінірек `Alt+Shift+D` керек болады: агент сол жақта, журналдар оң жақта.
- **macOS** — `Cmd+Space` басып, `terminal` деп теріп, Enter пернесін бас.
- **Linux** — көп ортада `Ctrl+Alt+T`.

Енді курсор тұрған жолды оқы: Windows-та ол қай shell-де тұрғаныңды айтады. Пәрменді басқа shell-ге қойсаң, құжаттамада тізілген екі қатенің бірін аласың ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)).

| Жол мынаған ұқсаса | Сен тұрған жер | Демек |
|---|---|---|
| `PS C:\Users\you>` | PowerShell | «PowerShell үшін» деп жазылған пәрмендер осында |
| `C:\Users\you>` | CMD | «CMD үшін» деп жазылған пәрмендер осында |
| `you@laptop:~$` | Git Bash, WSL, macOS немесе Linux | кез келген оқулықтағы macOS/Linux жолы сол күйінде жұмыс істейді |

## Орнат, содан соң дәлелде

<Steps>

<Step title="Node орнат — npm онымен бірге келеді">
Node.js-тің ресми бетінен өз жүйеңе арналған **LTS** нұсқасын ал: Windows-та `.msi`, macOS-та `.pkg`, Linux-та сол беттегі өз дистрибутивіңе арналған нұсқау. Әдепкі параметрлерді өзгертпе.

LTS — long-term support, яғни ұзақ мерзімді қолдау: ең қызықсыз нұсқа, ал саған дәл сол керек. 20-нұсқадан жоғарысы жарайды, бірақ ең жаңасын ал: Claude Code-ты npm арқылы орнатсаң, Node.js 22 немесе одан жаңасы керек ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)).

Содан соң **терминалды жауып, жаңасын аш.** Ашық тұрған терминал орнатушының ортаны өзгерткенін байқамайды — жаңа бағдарламаның бұзылған болып көрінуінің ең жиі себебі осы.

<Terminal title="тексеру" copy={false}>

```text
> node -v
v22.20.0

> npm -v
10.9.3
```

</Terminal>

Сенде сандар жоғарырақ болады. Маңыздысы — пішіні: `node -v` жауабы `v` әрпі мен цифрлар, `npm -v` жауабы — цифрлар. npm Node-пен бірге келеді, оны бөлек орнатпайсың.
</Step>

<Step title="git орнат">
**Windows:** [Git for Windows](https://git-scm.com/downloads/win) жүктеп алып, әдепкі параметрлермен орнат. Anthropic құжаттамасы мұны Claude Code үшін міндетті емес дейді де, сонда да кеңес береді: git тұрса, Claude Code-тың Bash құралы Git Bash болады; болмаса, PowerShell құралына ауысады ([орнату нұсқаулығы](https://code.claude.com/docs/en/setup)). git саған 02-практикадан бастап бәрібір керек.

**macOS:** `git --version` пәрменін орында. git жоқ болса, macOS әзірлеушіге арналған пәрмен жолы құралдарын ұсынады — келіс, күте тұр да, пәрменді қайта орында.

**Linux (Debian/Ubuntu):** `sudo apt install git`.

<Terminal title="тексеру" copy={false}>

```text
> git --version
git version 2.51.0
```

</Terminal>

Мұнда да нөмірдің маңызы жоқ. `git version` деген сөздер мен цифрлар — бар маңыздысы сол.
</Step>

<Step title="VS Code орнат және онымен қалта аш">
VS Code — тегін редактор, оның өзегі ашық бастапқы кодты ([microsoft/vscode](https://github.com/microsoft/vscode)). Microsoft сайтынан жүктеп орнат, не Windows-та `winget install Microsoft.VisualStudioCode` пәрменін орында.

Содан соң ең маңызды істі орында: **File → Open Folder**. Файлды емес, қалтаны. Осы курстағы бәрі де, агенттің әрекеті де бір қалтаның шегінде жүреді.

<Callout type="warn" title="Кеңейтім деген — пәрмен емес">
Кейінірек Claude Code кеңейтімін қосуың мүмкін: Extensions панелі (`Ctrl+Shift+X`), «Claude Code» деп ізде, содан соң Command Palette (`Ctrl+Shift+P`) → «Claude Code» → Open in New Tab. Кеңейтім CLI-дың өз жеке көшірмесін ала келеді және `claude` пәрменін PATH-қа **қоспайды** ([VS Code интеграциясы](https://code.claude.com/docs/en/vs-code)). Сондықтан адамдар оны орнатып, терминалда `claude` деп тереді, "not recognized" алады да, орнату сәтсіз деп ойлайды. Бұл — екі бөлек орнату.
</Callout>
</Step>

<Step title="Курстың соңына дейін өмір сүретін қалтаңды жаса">
Бір жоба — бір қалта. Жұмыс үстелі емес, үй каталогы емес — аты бар бөлек қалта.

<Terminal title="powershell">

```powershell
cd $HOME\Documents
mkdir qairu-event
cd qairu-event
```

</Terminal>

<Terminal title="bash">

```bash
cd ~/Documents
mkdir qairu-event
cd qairu-event
```

</Terminal>

Бір қатарға біріктірсең: PowerShell пәрмендерді `;` арқылы, Bash `&&` арқылы бөледі — келесі кестедегі екі қате осыдан шығады.

Агентті үй қалтаңда немесе жұмыс үстелінде іске қоссаң, өзіңдегі барлық файлды оқуға және индекстеуге бергенің. Алдымен `cd` арқылы жоба қалтасына кір — әр жолы.
</Step>

<Step title="Бәрін бір жаңа терминалда дәлелде">
Барлық орнатудан **кейін** ашылған терминалда, `qairu-event` қалтасының ішінде тұрып:

<Terminal title="тексеру">

```bash
node -v
git --version
```

</Terminal>

Екі нұсқа нөмірі, қатесіз. Содан соң қалтаны VS Code-та аш — File → Open Folder, немесе орнатушы қосқан болса `code .` — және сол жақтағы (бос) файлдар ағашын көр.

Дайын болу деген — екі сан және бір қалта.
</Step>

</Steps>

## Windows қарсыласа

Бұл залдағылардың басым бөлігі Windows-та отыр, ал оқулықтардың көбі Windows үшін жазылмаған. Пәрменді қайта-қайта орындағанша, хабарды оқып шық. Әр жол Anthropic-тің [орнату](https://code.claude.com/docs/en/setup) және [орнату ақауларын жою](https://code.claude.com/docs/en/troubleshoot-install) беттерінен алынған.

| Хабар | Шын мәнінде не болды | Шешімі |
|---|---|---|
| `'x' is not recognized` | ол қалта PATH-та жоқ — немесе терминал орнатудан бұрын ашылған | алдымен **жаңа** терминал аш; сонда да болмаса, қалта шынымен PATH-та жоқ |
| `The token '&&' is not a valid statement separator` | CMD пәрмені PowerShell-ге қойылған | пәрмендердің арасына `;` қой немесе shell ауыстыр |
| `'irm' is not recognized` | PowerShell пәрмені CMD-ге қойылған | PowerShell ашып, сол жерде орында |
| `running scripts is disabled on this system` | PowerShell-дің орындау саясаты скрипт қабықшасын бұғаттап тұр; құжаттамада дәл осы қате npm қабықшалары үшін көрсетілген | сол пәрменді CMD-де немесе Git Bash-те орында — онда PowerShell саясаты жүрмейді |
| `Claude Code does not support 32-bit Windows` | «PowerShell (x86)» ашылған | оны жауып, кәдімгі PowerShell немесе Windows Terminal аш |
| `syntax error near unexpected token '<'` немесе curl 403 қайтарса | орнату скрипті HTML бет қайтарған — желі немесе аймақ бойынша бұғаттау | басқа желіні байқап көр; Қазақстанның өзіне қолдау бар, төменде қара |

<Callout type="tip" title="PATH ережесі, бір жолда">
PATH — терминал бағдарламаларды іздейтін қалталар тізімі. Орнатушы оған жаңа жол қоса алады, ал ашық тұрған терминал оны қайта оқымайды. Сондықтан шешімі мынау: терезені жап, жаңасын аш, пәрменді қайта орында.
</Callout>

GitHub пакеті Copilot Pro емес, Copilot Student береді: GPT-5.3-Codex, GPT-5.4, Claude Opus не Claude Sonnet-ті қолмен таңдай алмайсың, тек Auto режимі бар, ал лимит айына 200 ЖИ-кредит, бір кредит — бір цент қолданыс. Тегін — әлі де тегін, тек жарнама меңзегеннен кішірек.

## Орнатуыңды ЖИ-ге тапсырып, жұмысыңды тексерт

Агент әзірге жоқ — ол 01-практикада — бірақ чат терезесі бар. Пәрмендерді орында, нақты нәтижені көшір де, мынаның қасына қой.

<Prompt title="Орнату дәрігері" where="claude.ai · or any AI chat, free plan is fine">

```text
Мен веб-әзірлеу курсына ноутбук дайындап жатырмын, оған Node, npm және git керек.
Менің операциялық жүйем: [Windows 11 / macOS / Ubuntu].

Терминалым дәл мынаны басып шығарды, ештеңесін өзгертпей көшірдім:

[мұнда node -v нәтижесін қой]
[мұнда npm -v нәтижесін қой]
[мұнда git --version нәтижесін қой]

Мына үш істі осы ретпен орында:
1. Node, npm және git-тің қайсысы дұрыс орнатылған, қайсысы орнатылмаған — соны айт.
2. Жоқ немесе тым ескі нәрсенің әрқайсысы үшін (маған Node 20 немесе жоғары керек)
```
