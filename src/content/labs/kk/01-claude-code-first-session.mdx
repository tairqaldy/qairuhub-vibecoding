<Lead>
Агентпен өткен алғашқы сеанстардың көбі бір себептен сәтсіз бітеді: адамдар оған бірден бірдеңе жасатқысы келеді. Сен керісінше істейсің. Орнатып, оны бір қалтаға бағыттайсың да, бүкіл алғашқы сеансты оған кодты *оқытуға* жұмсайсың — содан кейін шынымен түсінген-түсінбегенін тексересің.
</Lead>

Соңында сенде жұмыс істейтін орнатылым, кез келген уақытта тастап кетіп қайта орала алатын сеанс және мәңгі сақтап қоятын бір промпт болады.

## Бұл қанша тұрады және ақшаң болмаса не істейсің

Claude Code тегін claude.ai жазылымына кірмейді. Саған Pro, Max, Team, Enterprise немесе Console API аккаунты керек ([орнату құжаттамасы](https://code.claude.com/docs/en/setup)). Ең арзан есік — айына $20 тұратын Pro, жылдық төлемде айына $17; [бағалар беті](https://claude.com/pricing) мұны «$200 billed up front» деп жазады. Pro сеансында әдепкі модель — Sonnet 5, ал «From $100 Per month» деп көрсетілген Max-та әдепкі модель — Opus 5 ([модель параметрлері](https://code.claude.com/docs/en/model-config)).

API кілті — әр токен үшін бөлек төлем: бір кешке арзан, әдетке айналса қымбат. Anthropic-тің өз [шығын құжаттамасы](https://code.claude.com/docs/en/costs) нақты қолданысты бір әзірлеушіге белсенді күніне шамамен $13, айына $150–250 деп бағалайды. Жазылым да шексіз емес: лимитің жылжымалы бес сағаттық және апталық терезе бойынша жаңарады, әрі ол Claude чаты мен Cowork-пен ортақ.

Қазақстан Anthropic-тің [қолдау көрсетілетін елдер тізімінде](https://www.anthropic.com/supported-countries) бар — claude.ai үшін де, API үшін де. Егер `App unavailable in region` деген жазуды көрсең, мәселе аккаунтта емес, елде немесе VPN-де ([ақаулықты жою](https://code.claude.com/docs/en/troubleshoot-install)).

<Callout type="info" title="Бұл айда ақшаң мүлде болмаса">
Оның орнына **Antigravity CLI** құралын орнат. Individual жоспары — $0, апталық лимиттермен, ал [бағалар беті](https://antigravity.google/pricing) сол тегін жоспардың астында Gemini 3.8 Flash, Gemini 3.1 Pro және Claude Sonnet пен Opus 4.6 модельдерін тізіп тұр. Қазақстанға қолдау көрсетіледі; жеке Google аккаунты керек және жасың 18-ден асуы тиіс ([FAQ](https://antigravity.google/docs/faq/)).

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

Сосын `cd` пәрменімен жобаңа кіріп, `agy` пәрменін орында. Бір ескерту, ешкімнің кеші босқа кетпесін: Gemini CLI құралы 2026 ж. 18 маусымда тегін пайдаланушылар мен Google AI Pro/Ultra жазылушыларына қызмет көрсетуді тоқтатты ([хабарландыру](https://github.com/google-gemini/gemini-cli/discussions/27274)), сондықтан оны «тегін нұсқа» деп атайтын әр оқулық ескірген. GitHub Copilot-та Free жоспары бар — айына 2000 код толықтыруы, чат пен агент шектеулі ([жоспарлар](https://github.com/features/copilot/plans)) — және GitHub Education арқылы студенттік жоспар: айына 200 ЖИ кредиті, модель таңдау жоқ ([GitHub талқылауы](https://github.com/orgs/community/discussions/189268)).

Бұдан кейінгі әр практика сол құралдарда да орындалады. Пәрмендері басқаша — `agy` құралы `AGENTS.md` файлын оқиды, Claude Code `CLAUDE.md` файлын оқиды — бірақ ойлау тәсілі бірдей, ал сен осында дәл сол ойлау тәсілі үшін келдің.
</Callout>

Тағы бір жол: тәлімгеріңнен `/passes` туралы сұра. [Пәрмендер құжаттамасында](https://code.claude.com/docs/en/commands) ол жарамды аккаунттан «a free week of Claude Code with friends» бөлісу деп сипатталған — яғни досыңа Claude Code-тың бір тегін аптасын сыйлау. Қандай аккаунттар жарамды екені жазылмаған, сондықтан болжамай, сұрап біл.

<Steps>

<Step title="Бір пәрменмен орнат">
Өз shell-іңе сәйкес жолды таңда. Windows-та `PS C:\` деп басталатын жол — PowerShell, ал `PS` жоқ `C:\` — CMD. Қате жолды қою — осы практикадағы ең жиі кездесетін сәтсіздік.

<Terminal title="macOS, Linux, WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Terminal>

<Terminal title="Windows PowerShell — әкімші құқығы керек емес">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Terminal>

<Terminal title="Windows CMD">
```batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```
</Terminal>

Бұл — нативті орнатушы, ол өзін фонда жаңартып отырады. Node да, WSL де керек емес: таза Windows жұмыс істейді. Git for Windows міндетті емес, бірақ оны [git-scm.com](https://git-scm.com/downloads/win) сайтынан бәрібір орнат — ол тұрса, Claude өзінің Bash құралын PowerShell-ге ауыспай, Git Bash арқылы іске қосады ([орнату құжаттамасы](https://code.claude.com/docs/en/setup)).
</Step>

<Step title="ЖАҢА терминал ашып, орнатылымды тексер">
Ескі терминал жаңа бағдарлама туралы білмейді. Жаңасын аш.

<Terminal title="тексеру">
```bash
claude --version
claude doctor
```
</Terminal>

`claude --version` пәрмені `2.1.269 (Claude Code)` тәрізді жол шығарады. `claude doctor` — орнатылым мен параметрлерді тек оқып шығатын диагностика; ол ештеңені бұза алмайды.

<Callout type="warn" title="command not found: claude">
Бағдарлама дұрыс орнады, тек shell оны көрмей тұр. Ол Windows-та `%USERPROFILE%\.local\bin\claude.exe`, macOS пен Linux-та `~/.local/bin/claude` жолында жатыр. Сол қалтаны PATH-қа қосып, жаңа терминалды қайта ашу керек ([ақаулықты жою](https://code.claude.com/docs/en/troubleshoot-install)).

```powershell
$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')
```

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc    # macOS zsh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc   # Linux bash
```

Тағы екі қатенің себебі бір жолға сыяды: `The token '&&' is not a valid statement separator` — CMD пәрмені PowerShell-ге қойылған, ал `'irm' is not recognized` — PowerShell пәрмені CMD-ге қойылған.
</Callout>
</Step>

<Step title="Оған оқитын нақты дүние бер">
`claude` пәрменін үй қалтаңда немесе жұмыс үстелінде ешқашан іске қоспа — ол жерден агент сенің бүкіл дүниеңді көріп, индекстей алады. Алдымен әрқашан `cd` пәрменімен жобаға кір. Кішкентай жобаң бар ма? Соны ал. Жоқ болса, мынаны жаса: үш минут кетеді, әрі ол агенттің жауабын кодпен өзің салыстыра алатындай шағын.

<Terminal title="PowerShell">
```powershell
mkdir qairu-cards; cd qairu-cards; git init
```
</Terminal>

<Terminal title="macOS, Linux, WSL">
```bash
mkdir qairu-cards && cd qairu-cards && git init
```
</Terminal>

Енді редакторда мына үш файлды жаса. `words.js`:

```js
const PAIRS = [
  { kk: 'кітап',  en: 'book' },
  { kk: 'терезе', en: 'window' },
  { kk: 'қала',   en: 'city' },
  { kk: 'су',     en: 'water' },
  { kk: 'дос',    en: 'friend' },
];
```

`index.html`:

```html
<!doctype html>
<html lang="kk">
  <head>
    <meta charset="utf-8" />
    <title>QAIRU Cards</title>
  </head>
  <body>
    <div id="card">...</div>
    <script src="words.js"></script>
    <script>
      let i = 0;
      let flipped = false;
      const card = document.getElementById('card');
      const render = () => { card.textContent = flipped ? PAIRS[i].en : PAIRS[i].kk; };
      card.onclick = () => { flipped = !flipped; render(); };
      document.onkeydown = (e) => {
        if (e.key === 'ArrowRight') { i = (i + 1) % PAIRS.length; flipped = false; render(); }
      };
      render();
    </script>
  </body>
</html>
```

`README.md`:

```md
# QAIRU Cards

A tiny Kazakh-English flashcard page. Open index.html in a browser.
Click a card to flip it. Use the Next button to move to the next word.
```

`README.md` файлын тағы бір рет оқып шық, сосын `index.html` файлын браузерде ашып, басып көр. Байқағаныңды әзірге өзіңде ұста.
</Step>

<Step title="Сеансты Manual режимінде баста">
<Terminal title="qairu-cards ішінде">
```bash
claude --permission-mode manual
```
</Terminal>

Pro, Max және Team жазылымдарында кәдімгі `claude` енді **auto** режимінде іске қосылады: онда әрекеттерді сенен сұраудың орнына екінші, жіктеуші модель тексереді ([рұқсат режимдері](https://code.claude.com/docs/en/permission-modes)). Бұл ыңғайлы, кейін соны қолданасың. Ал алғашқы төрт практикада Manual режимін мәжбүрлеп қос: ол тек оқиды, қалғанының бәрін сұрап барып істейді — сонда агенттің не істегісі келгенін шынымен көресің.

Бірінші рет іске қосқанда жүйеге кіру үшін браузер ашылады. Деректер сақталады, сондықтан бұл бір-ақ рет болады; `/login` аккаунтты ауыстырады, `/logout` жүйеден шығарады. Кез келген қалтада Claude-ты алғаш іске қосқанда, оған қоса жұмыс қалтасына сену туралы терезе шығады.

Жоғарғы жолақта оқуға тұрарлық үш нәрсе тұрады: нұсқа, ағымдағы модель және жұмыс қалтасы. Қалтаны тексер. Егер ол `qairu-cards` болмаса, `Ctrl+C` тіркесімін екі рет басып, дұрыс жерге `cd` жаса. Астындағы күй жолағында `manual mode on` деп тұруы керек.

<Callout type="danger" title="Бір орта айнымалысы саған ақы жаздырып жіберуі мүмкін">
Егер ортаңда `ANTHROPIC_API_KEY` орнатылған болса, Claude Code браузер арқылы кіруді өткізіп жіберіп, сол кілтті растауды сұрайды — осылайша сені жазылымнан әр токен үшін төлеуге үнсіз көшіреді ([жылдам бастау](https://code.claude.com/docs/en/quickstart)). Оны әдейі қоймаған болсаң, бастамас бұрын өшіріп таста.
</Callout>
</Step>

<Step title="Бірдеңе сұрамас бұрын басқаруды үйрен">
Мыналарды сеанстың ішінде, нақты сұрақ қоймай тұрып, ретімен жаса.

- `/help` — барлық пәрмен. Олар тоқсанға жуық; саған он бесі жетеді.
- Бос жолда `?` — пернелер тіркесімдерінің панелі.
- `! git status` — shell режимі. Пәрменді өзің орындайсың, ал нәтижесі әңгімеге түсіп қалады.
- `Shift+Tab` — рұқсат режимдерін кезекпен ауыстырады. Бірнеше рет басып, әр жолы күй жолағын оқы: `manual mode on`, `accept edits on`, `plan mode on`. Соңында қайтадан Manual режимінде тоқта.

Сынап көрудің орнына жаттап алатын екі перне: **`Esc`** Claude-ты әрекет ортасында тоқтатады да, оған дейін істелгенін сақтап қалады, ал **`Ctrl+O`** транскрипт терезесін ашады — онда әр құрал шақыруы егжей-тегжейлі көрінеді. Бұл тізімдегінің бәрі [интерактив режим құжаттамасынан](https://code.claude.com/docs/en/interactive-mode) алынды.

Соңында `/usage` пәрменін орында. Ол жазылым лимиттерінің жолақтарын және токендердің қайда кеткенін көрсетеді. Жазылымда отырсаң, доллармен берілген санға қарама — құжаттамада ол тек API пайдаланушылары үшін мағыналы екені анық жазылған ([шығындар](https://code.claude.com/docs/en/costs)).
</Step>

<Step title="Өзгертпес бұрын зерттетіп ал">
Міне, сол промпт. Дәл осылай тер немесе көшіріп қой. Ол не істеп тұрғанына назар сал: өзгеріс енгізуге тыйым салады, оқу аясын бір шағын жобамен шектейді, сен тексере алатын нақты тұжырым сұрайды және соңында агенттің өзіне сенен сұрақ қойғызады.

<Prompt title="Өзгертпес бұрын зерттеу" where="Claude Code · Manual mode">
```text
Әзірге ешқандай файлды өзгертпе.

Осы жобаны оқып шығып, қарапайым мәтінмен жауап бер:
1. Ол не істейді? Екі сөйлеммен айт.
2. Әр файлды тізіп шық та, әрқайсысы не үшін керегін жаз.
3. Деректер қай жерде тұр, ал экранға қай жерде шығады?
4. README уәде етіп тұрған, бірақ код шын мәнінде істемейтін бір нәрсені ата.
5. Мен тағы 200 сөз жұбын қоссам, ең бірінші не бұзылады?

Содан кейін тоқта да, менен келесі не жасағым келетіні туралы бір сұрақ сұра.
```
</Prompt>

Агенттің іздеп, файлдарды оқып жатқанын көресің. Ол контекстті өзі керегінше жинайды — кодты сен қолмен қоймайсың.
</Step>

<Step title="Жауапты көңіл-күймен емес, өлшеммен бағала">
Жақсы жауап төрт нәрсені істейді. Соларды белгілеп шық:

1. **Үш файлдың атын да атайды** және `words.js` деректерді сақтайтынын, ал `index.html` бір файлдың ішінде әрі HTML белгілеуін, әрі логиканы ұстап тұрғанын айтады.
2. **README-дегі сәйкессіздікті табады.** `README.md` ішінде Next түймесі уәде етілген. Кодта ешқандай түйме жоқ — тек оң жақ көрсеткі пернесі бар. Мұны байқамаса, ол үстірт шолып шыққан.
3. **5-сұраққа болжаммен емес, нақты механизммен жауап береді**: барлық жұп бірден жүктеледі, араластыру жоқ, үлгерім сақталмайды, беттерге бөлу жоқ.
4. **Сұрақпен аяқтайды**, өйткені сен солай сұрадың.

Нашар жауаптың белгісі — бірде-бір файлдан дәйексөз келтірмейтін, бірақ еркін де сенімді жазылған мәтін. Сондықтан оны тексер:

<Prompt title="Жұмысын көрсеттір" where="Claude Code · Manual mode">
```text
Бес жауабыңның қайсысына сенімің ең аз, және оны шешу үшін нақты нені оқыдың?
Сүйенген файл атауы мен жолдарын көрсет.
```
</Prompt>

Құжаттамада бұл сәтсіздіктің өз атауы бар: алдымен сеніп, сосын тексеру алшақтығы — сырты дұрыс көрінетін, бірақ шекті жағдайларды жіберіп алатын код. Олардың шешімі — агентке өзі іске қоса алатын тексеріс беру: тест, скрипт немесе скриншот. Ережесі бір жолға сыяды: тексере алмасаң, шығарма ([үздік тәжірибелер](https://code.claude.com/docs/en/best-practices)).
</Step>

<Step title="/clear пен /compact — сеансыңды құтқаратын айырмашылық">
`/context` пәрменін орында. Ол қазір терезені не толтырып тұрғанын көрсетеді: әңгіме, оқылған файлдардың бәрі, пәрмен нәтижелері, жад файлдары. Sonnet 5 пен Opus 5 миллион токен ұстайды және әдепкіде шамамен 967 мың токенде автоматты түрде сығады ([модель параметрлері](https://code.claude.com/docs/en/model-config)), бірақ терезе толған сайын сапа бәрібір төмендейді. Үлкен терезе саған сапа емес, уақыт сатып береді.

Ереже, әрқайсысы бір жол:

- **`/compact`** әңгімені қысқаша жинақтап, орын босатады, бірақ жіпті үзбейді. Оны бағыттап жібер: `/compact keep the file list and the README mismatch`. Бір тапсырма ұзаққа созылып кеткенде қолдан.
- **`/clear`** контексті бос жаңа әңгіме бастайды. Ол бір тиын да тұрмайды. Келесі істейтін ісіңнің алдыңғысына ешқандай қатысы болмаса, соны қолдан.

Қазір дәл сол ретпен істе. Нұсқаумен бірге compact жаса, `/context` пәрменін қайта орында да, санның қалай түскенін бақыла. Сосын `/rename first-session` жаса, сонда ертең `/resume` осы әңгімені тауып алады, содан соң `/clear`. Бос сеанста `/compact` пәрменін тағы бір рет байқап көр: ол `Not enough messages to compact.` деп жауап береді — бұл сығудың құралға емес, әңгімеге қатысты екенінің дәлелі.

Құжаттамадағы бір қағиданы көшіріп алуға тұрарлық: Claude-ты бір нәрсе бойынша екі рет түзеткен болсаң, үшінші рет түзетуге кіріспе. `/clear` жаса да, жақсырақ промпт жаз.
</Step>

<Step title="Шығып кет те, қайта орала алатыныңды дәлелде">
`/exit` деп тер немесе `Ctrl+D` тіркесімін екі рет бас. Сосын сол қалтадан:

<Terminal title="қайтадан терминалда">
```bash
claude -c
```
</Terminal>

`-c` осы қалтадағы ең соңғы әңгімені жалғастырады. Сеансың сол орнында тұр, өзі құрастырған файлдар тізімімен бірге. Тағы да шық. Бітті.
</Step>

</Steps>

## Тек оқуға арналған алғашқы сеанс неге жай жаттығу емес

Бұл — нағыз дағданың өзі. [Claude Code құжаттамасы](https://code.claude.com/docs/en/best-practices) атайтын бес сәтсіздік үлгісінің үшеуі кодқа емес, контекстке қатысты: бір әңгімеге бір-біріне қатысы жоқ тапсырмаларды үйіп тастау; терезе сәтсіз әрекеттерге толғанша бір қатені қайта-қайта түзету; және бір сөйлеммен шектеп қоюға болатын сұраққа жауап іздеп, жүздеген файлды оқып шығатын аясыз зерттеу.

Жобаңды оқып шыққан агент пен болжап отырған агент басқаша жауап береді, бірақ мәтінге қарап бұл айырманы байқау мүмкін емес. 7-қадам дәл сол үшін бар. «Мұны шешу үшін нені оқыдың?» деп сұрау саған бір ғана қосымша промпт тұрады, ал орнына осы курстағы ең қымбат қателер тобын ұстап береді.
