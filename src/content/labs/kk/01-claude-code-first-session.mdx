<Lead>
Агентпен өткен алғашқы сеанстардың көбі бір себептен сәтсіз бітеді: адамдар оған бірден бірдеңе жасатқысы келеді. Сен керісінше істе. Орнат, бір қалтаға бағытта да, бүкіл алғашқы сеансты кодты *оқытуға* жұмса — сосын түсінген-түсінбегенін тексер.
</Lead>

## Бұл қанша тұрады, ақшаң болмаса не істейсің

Claude Code тегін claude.ai жазылымына кірмейді. Саған Pro, Max, Team, Enterprise немесе Console API аккаунты керек ([орнату құжаттамасы](https://code.claude.com/docs/en/setup)). Ең арзан есік — Pro: айына $20, жылдық төлемде айына $17. [Бағалар беті](https://claude.com/pricing) мұны «$200 billed up front» деп жазады. Pro-да әдепкі модель — Sonnet 5. «From $100 Per month» деп көрсетілген Max-та әдепкі модель — Opus 5 ([модель параметрлері](https://code.claude.com/docs/en/model-config)).

API кілті — әр токен үшін бөлек төлем ([02-модуль](/kk/learn/ai-in-plain-language/)): бір кешке арзан, әдетке айналса қымбат. Anthropic-тің [шығын құжаттамасы](https://code.claude.com/docs/en/costs) нақты қолданысты бір әзірлеушіге белсенді күніне шамамен $13, айына $150–250 деп бағалайды. Жазылым да шексіз емес: лимитің жылжымалы бес сағаттық және апталық терезе бойынша жаңарады, әрі Claude чаты мен Cowork-пен ортақ.

Қазақстан Anthropic-тің [қолдау көрсетілетін елдер тізімінде](https://www.anthropic.com/supported-countries) бар — claude.ai үшін де, API үшін де. `App unavailable in region` деген жазу шықса, мәселе аккаунтта емес, елде немесе VPN-де ([ақаулықты жою](https://code.claude.com/docs/en/troubleshoot-install)).

<Callout type="info" title="Бұл айда ақшаң мүлде болмаса">
Оның орнына **Antigravity CLI** құралын орнат. Individual жоспары — $0, апталық лимиттермен. [Бағалар беті](https://antigravity.google/pricing) сол жоспардың астында Gemini 3.8 Flash, Gemini 3.1 Pro және Claude Sonnet пен Opus 4.6 модельдерін тізіп тұр. Қазақстанға қолдау бар; жеке Google аккаунты керек, жасың 18-ден асуы тиіс ([FAQ](https://antigravity.google/docs/faq/)).

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

Сосын `cd` пәрменімен жобаңа кіріп, `agy` пәрменін орында. Бір ескерту: Gemini CLI құралы 2026 ж. 18 маусымда тегін пайдаланушылар мен Google AI Pro/Ultra жазылушыларына қызмет көрсетуді тоқтатты ([хабарландыру](https://github.com/google-gemini/gemini-cli/discussions/27274)), сондықтан оны «тегін нұсқа» деп атайтын әр оқулық ескірген. GitHub Copilot-тың Free жоспары айына 2000 код толықтыруын береді, чат пен агент шектеулі ([жоспарлар](https://github.com/features/copilot/plans)); GitHub Education оның үстіне айына 200 ЖИ кредитін қосады, модель таңдау жоқ ([GitHub талқылауы](https://github.com/orgs/community/discussions/189268)).

Бұдан кейінгі әр практика сол құралдарда да орындалады. Тек пәрмендері басқа: `agy` құралы `AGENTS.md` файлын оқиды, Claude Code — `CLAUDE.md` файлын.
</Callout>

Тағы бір жол: тәлімгеріңнен `/passes` туралы сұра. [Пәрмендер құжаттамасы](https://code.claude.com/docs/en/commands) оны жарамды аккаунттан «a free week of Claude Code with friends» бөлісу деп сипаттайды: досыңа Claude Code-тың бір тегін аптасын сыйлайсың. Қандай аккаунттар жарамды екені жазылмаған, сондықтан сұрап біл.

<Steps>

<Step title="Бір пәрменмен орнат">
Өз shell-іңе сәйкес жолды таңда. Windows-та `PS C:\` деп басталатын жол — PowerShell, ал `PS` жоқ `C:\` — CMD. Қате жолды қою — осы практикадағы ең жиі қате.

<Terminal title="macOS, Linux, WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Terminal>

<Terminal title="Windows PowerShell — әкімші құқығы керек емес">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Terminal>

<Terminal title="Windows CMD">
```batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```
</Terminal>

Нативті орнатушы өзін фонда жаңартып отырады. Node да, WSL де керек емес: таза Windows жұмыс істейді. Git for Windows міндетті емес, бірақ оны [git-scm.com](https://git-scm.com/downloads/win) сайтынан бәрібір орнат: ол тұрса, Claude өз Bash құралын PowerShell арқылы емес, Git Bash арқылы іске қосады ([орнату құжаттамасы](https://code.claude.com/docs/en/setup)).
</Step>

<Step title="ЖАҢА терминал ашып, орнатылымды тексер">
Ескі терминал жаңа бағдарлама туралы білмейді. Жаңасын аш.

<Terminal title="тексеру">
```bash
claude --version
claude doctor
```
</Terminal>

`claude --version` пәрмені `2.1.269 (Claude Code)` тәрізді жол шығарады. `claude doctor` — тек оқитын диагностика, ол ештеңені бұза алмайды.

<Callout type="warn" title="command not found: claude">
Бағдарлама дұрыс орнады, тек shell оны көрмей тұр. Ол Windows-та `%USERPROFILE%\.local\bin\claude.exe`, macOS пен Linux-та `~/.local/bin/claude` жолында жатыр. Сол қалтаны PATH-қа қос та, жаңа терминал аш ([ақаулықты жою](https://code.claude.com/docs/en/troubleshoot-install)).

```powershell
$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')
```

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc    # macOS zsh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc   # Linux bash
```

Тағы екі қате, әрқайсысының бір ғана себебі бар: `The token '&&' is not a valid statement separator` — CMD пәрмені PowerShell-ге қойылған, ал `'irm' is not recognized` — PowerShell пәрмені CMD-ге қойылған.
</Callout>
</Step>

<Step title="Оған оқитын нақты дүние бер">
`claude` пәрменін үй қалтаңда немесе жұмыс үстелінде ешқашан іске қоспа: ол жерден агент бүкіл дүниеңді индекстей алады. Алдымен `cd` пәрменімен жобаға кір. Кішкентай жобаң бар ма? Соны ал. Жоқ болса, мынаны жаса: үш минут кетеді, әрі жауабын өзің тексере аласың.

<Terminal title="PowerShell">
```powershell
mkdir qairu-cards; cd qairu-cards; git init
```
</Terminal>

<Terminal title="macOS, Linux, WSL">
```bash
mkdir qairu-cards && cd qairu-cards && git init
```
</Terminal>

Енді редакторда мына үш файлды жаса. `words.js`:

```js
const PAIRS = [
  { kk: 'кітап',  en: 'book' },
  { kk: 'терезе', en: 'window' },
  { kk: 'қала',   en: 'city' },
  { kk: 'су',     en: 'water' },
  { kk: 'дос',    en: 'friend' },
];
```

`index.html`:

```html
<!doctype html>
<html lang="kk">
  <head>
    <meta charset="utf-8" />
    <title>QAIRU Cards</title>
  </head>
  <body>
    <div id="card">...</div>
    <script src="words.js"></script>
    <script>
      let i = 0;
      let flipped = false;
      const card = document.getElementById('card');
      const render = () => { card.textContent = flipped ? PAIRS[i].en : PAIRS[i].kk; };
      card.onclick = () => { flipped = !flipped; render(); };
      document.onkeydown = (e) => {
        if (e.key === 'ArrowRight') { i = (i + 1) % PAIRS.length; flipped = false; render(); }
      };
      render();
    </script>
  </body>
</html>
```

`README.md`:

```md
# QAIRU Cards

A tiny Kazakh-English flashcard page. Open index.html in a browser.
Click a card to flip it. Use the Next button to move to the next word.
```

`README.md` файлын тағы бір рет оқы, сосын `index.html` файлын браузерде ашып, басып көр. Байқағаныңды әзірге өзіңде ұста.
</Step>

<Step title="Сеансты Manual режимінде баста">
<Terminal title="qairu-cards ішінде">
```bash
claude --permission-mode manual
```
</Terminal>

Pro, Max және Team жазылымдарында кәдімгі `claude` енді **auto** режимінде іске қосылады: әрекеттерді сенен сұраудың орнына екінші, жіктеуші модель тексереді ([рұқсат режимдері](https://code.claude.com/docs/en/permission-modes), [07-модуль](/kk/learn/the-agent/)). Алғашқы төрт практикада Manual режимін мәжбүрлеп қос: ол тек оқиды, қалғанын сұрап барып істейді. Сонда агенттің не істегісі келгенін көресің.

Бірінші рет іске қосқанда жүйеге кіру үшін браузер ашылады. Деректер сақталады, сондықтан бұл бір-ақ рет болады; `/login` аккаунтты ауыстырады, `/logout` жүйеден шығарады. Кез келген қалтада Claude-ты алғаш қосқанда жұмыс қалтасына сену туралы терезе де шығады.

Жоғарғы жолақта үш нәрсе тұрады: нұсқа, модель және жұмыс қалтасы. Қалта `qairu-cards` болмаса, `Ctrl+C` тіркесімін екі рет басып, дұрыс жерге `cd` жаса. Күй жолағында `manual mode on` деп тұруы керек.

<Callout type="danger" title="Бір орта айнымалысы саған ақы жаздырып жіберуі мүмкін">
Ортаңда `ANTHROPIC_API_KEY` орнатылған болса, Claude Code браузер арқылы кіруді өткізіп жіберіп, сол кілтті растауды сұрайды — сөйтіп сені жазылымнан әр токен үшін төлеуге үнсіз көшіреді ([жылдам бастау](https://code.claude.com/docs/en/quickstart)). Оны әдейі қоймаған болсаң, бастамас бұрын өшіріп таста.
</Callout>
</Step>

<Step title="Бірдеңе сұрамас бұрын басқаруды үйрен">
Мыналарды сеанстың ішінде, нақты сұрақ қоймай тұрып ретімен жаса.

- `/help` — барлық пәрмен. Олар тоқсанға жуық; саған он бесі жетеді.
- Бос жолда `?` — пернелер тіркесімдерінің панелі.
- `! git status` — shell режимі. Пәрменді өзің орындайсың, ал нәтижесі әңгімеге түсіп қалады.
- `Shift+Tab` — рұқсат режимдерін кезекпен ауыстырады. Бірнеше рет басып, әр жолы күй жолағын оқы: `manual mode on`, `accept edits on`, `plan mode on`. Соңында қайтадан Manual режимінде тоқта.

Жаттап алатын екі перне: **`Esc`** Claude-ты әрекет ортасында тоқтатады да, оған дейін істелгенін сақтап қалады, ал **`Ctrl+O`** транскрипт терезесін ашады — онда әр құрал шақыруы егжей-тегжейлі көрінеді. Бәрі [интерактив режим құжаттамасында](https://code.claude.com/docs/en/interactive-mode) бар.

Соңында `/usage` пәрменін орында: жазылым лимиттері мен токендердің қайда кеткені көрінеді. Жазылымда отырсаң, доллармен берілген санның мәні жоқ, ол тек API пайдаланушылары үшін маңызды ([шығындар](https://code.claude.com/docs/en/costs)).
</Step>

<Step title="Өзгертпес бұрын зерттетіп ал">
Мынаны дәл осылай тер немесе көшіріп қой. Ол өзгерісті тыйып, оқу аясын шектейді, сен тексере алатын нақты тұжырым сұрайды, соңында агентке сенен сұрақ қойғызады.

<Prompt title="Өзгертпес бұрын зерттеу" where="Claude Code · Manual mode">
```text
Әзірге ешқандай файлды өзгертпе.

Осы жобаны оқып шығып, қарапайым мәтінмен жауап бер:
1. Ол не істейді? Екі сөйлеммен айт.
2. Әр файлды тізіп шық та, әрқайсысы не үшін керегін жаз.
3. Деректер қай жерде тұр, ал экранға қай жерде шығады?
4. README уәде етіп тұрған, бірақ код шын мәнінде істемейтін бір нәрсені ата.
5. Мен тағы 200 сөз жұбын қоссам, ең бірінші не бұзылады?

Содан кейін тоқта да, менен келесі не жасағым келетіні туралы бір сұрақ сұра.
```
</Prompt>

Агенттің іздеп, файлдарды оқып жатқанын көресің. Контекстті ол өзі керегінше жинайды — кодты сен қолмен қоймайсың.
</Step>

<Step title="Жауапты көңіл-күймен емес, өлшеммен бағала">
Жақсы жауап төрт нәрсені істейді:

1. **Үш файлдың атын да атайды** және `words.js` деректерді сақтайтынын, ал `index.html` бір файлда әрі HTML белгілеуін, әрі логиканы ұстап тұрғанын айтады.
2. **README-дегі сәйкессіздікті табады.** `README.md` ішінде Next түймесі уәде етілген. Кодта түйме жоқ — тек оң жақ көрсеткі пернесі бар. Мұны байқамаса, үстірт шолып шыққан.
3. **5-сұраққа болжаммен емес, нақты механизммен жауап береді**: барлық жұп бірден жүктеледі, араластыру жоқ, үлгерім сақталмайды, беттерге бөлу жоқ.
4. **Сұрақпен аяқтайды**, өйткені сен солай сұрадың.

Нашар жауаптың белгісі — еркін де сенімді жазылған, бірақ бірде-бір файлға сілтемейтін мәтін. Сондықтан тексер:

<Prompt title="Жұмысын көрсеттір" where="Claude Code · Manual mode">
```text
Бес жауабыңның қайсысына сенімің ең аз, және оны шешу үшін нақты нені оқыдың?
Сүйенген файл атауы мен жолдарын көрсет.
```
</Prompt>

Құжаттама бұны «алдымен сеніп, сосын тексеру алшақтығы» деп атайды: сырты дұрыс көрінетін, бірақ шекті жағдайларды жіберіп алатын код. Шешімі — агент өзі іске қоса алатын тексеріс: тест, скрипт немесе скриншот ([10-модуль](/kk/learn/test-and-quality/)). Ережесі: тексере алмасаң, шығарма ([үздік тәжірибелер](https://code.claude.com/docs/en/best-practices)).
</Step>

<Step title="/clear пен /compact — сеансыңды құтқаратын айырмашылық">
`/context` пәрменін орында. Ол терезені не толтырып тұрғанын көрсетеді: әңгіме, оқылған файлдар, пәрмен нәтижелері, жад файлдары. Sonnet 5 пен Opus 5 миллион токен ұстайды және әдепкіде шамамен 967 мың токенде автоматты түрде сығады ([модель параметрлері](https://code.claude.com/docs/en/model-config)), бірақ терезе толған сайын сапа төмендейді ([02-модуль](/kk/learn/ai-in-plain-language/)). Үлкен терезе сапа емес, уақыт сатып береді.

- **`/compact`** әңгімені қысқаша жинақтап, орын босатады, бірақ жіпті үзбейді. Оны бағыттап жібер: `/compact keep the file list and the README mismatch`. Бір тапсырма ұзаққа созылғанда қолдан.
- **`/clear`** контексті бос жаңа әңгіме бастайды. Бір тиын да тұрмайды. Келесі ісіңнің алдыңғысына қатысы болмаса, соны қолдан.

Дәл сол ретпен істе. Нұсқаумен бірге compact жаса, `/context` пәрменін қайта орында да, санның түскенін бақыла. Сосын `/rename first-session` жаса — ертең `/resume` осыны тауып алады — содан соң `/clear`. Бос сеанста `/compact` пәрменін тағы байқап көр: `Not enough messages to compact.` Сығу құралға емес, әңгімеге қатысты.

Көшіріп алуға тұрарлық бір қағида: Claude-ты бір нәрсе бойынша екі рет түзеткен болсаң, үшінші рет түзетуге кіріспе. `/clear` жаса да, жақсырақ промпт жаз.
</Step>

<Step title="Шығып кет те, қайта орала алатыныңды дәлелде">
`/exit` деп тер немесе `Ctrl+D` тіркесімін екі рет бас. Сосын сол қалтадан:

<Terminal title="қайтадан терминалда">
```bash
claude -c
```
</Terminal>

`-c` осы қалтадағы ең соңғы әңгімені жалғастырады. Сеансың сол орнында тұр, өзі құрастырған файлдар тізімімен бірге. Тағы да шық. Бітті.
</Step>

</Steps>

## Тек оқуға арналған алғашқы сеанс неге жай жаттығу емес
