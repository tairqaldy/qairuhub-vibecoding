<Lead>
Қазір сен бір шағын нәрсені екі рет, мүмкін үш рет жасайсың. Мұның мәні — Claude Code-та үйренген циклің *құралға тәуелсіз* екенін дәлелдеу. Зерттеу, жоспарлау, мақұлдау, тексеру, commit — бұл кез келген құралда бірдей жұмыс істейді. Өзгеретіні — пернелер тіркесімі ғана.
</Lead>

Бір жылдың ішінде Gemini CLI тегін пайдаланушыларға қызмет көрсетуін тоқтатты, Windsurf Devin Desktop болып өзгерді, Roo Code репозиторийі мұрағатқа түсті, Cursor-ды SpaceX сатып алды, ал GitHub Copilot-тағы premium сұрауларды токенмен есептелетін кредитке ауыстырды. Шеберлігің түймелердің қай жерде тұрғанын білуден тұрса, бір ғана өнім шешімі оны жоққа шығарады. Ал цикл мен бір нұсқаулық файл сенімен бірге көшіп отырады.

## Бастамас бұрын: бір қалта, бір commit, бір тапсырма

<Terminal title="bash">
```bash
mkdir vibe-demo
cd vibe-demo
git init
git commit --allow-empty -m "empty start"
```
</Terminal>

Әр құралдағы тапсырма біреу: бағамы кодтың ішіне жазып қойылған, бір беттен тұратын теңге/USD конвертері. Таза HTML/CSS/JS, build қадамы жоқ. Бес минутта бітетіндей шағын, бірақ нашар жоспар бірден көрінетіндей нақты.

<Callout type="warn" title="Осы практикумның басты ережесі">
Әр ірі промпттың алдында commit жаса. Бір түстен кейін бір қалтада үш агент жүгіртсең — ұнаған жұмысыңнан айырылудың дәл өзі осы. `git` — олардың бәрінде бірдей істейтін жалғыз «кері қайтару» түймесі.
</Callout>

## Cursor: жоспарлау қадамы — пернелер тіркесімі

Ішіне агент салынған VS Code fork-ы. Hobby жоспарына карта керек емес; Pro — айына $20, ал [Cursor-дың өз баға құжаттамасы](https://cursor.com/docs/account/pricing) агентті күнде қолданатындардың жалпы шығынын айына $60–$100 деп есептейді. [2026 ж. 14 тамыздан бері](https://cursor.com/blog) ол SpaceX-ке тиесілі, ал [бағалар беті](https://cursor.com/pricing) енді Claude мен GPT-мен қатар Grok-қа қолжетімділікті де тізеді.

<Steps>
<Step title="Орнат та, қалтаны аш">
[cursor.com](https://cursor.com) сайтынан жүктеп ал, Google немесе GitHub арқылы кір, содан соң File → Open Folder → `vibe-demo`.
</Step>

<Step title="Агентті ашып, оны Plan режиміне ауыстыр">
`Ctrl+I` (macOS-та `Cmd+I`) агентті ашады. Агенттің енгізу өрісінде `Shift+Tab` Plan режиміне ауыстырады — Claude Code-тағы plan mode-пен бірдей идея. Ол файл емес, жоспар жазады.

<Prompt title="Жоспар промпты" where="Cursor · agent input, Plan mode (Shift+Tab)">
```text
Бағамы кодтың ішіне жазып қойылған, бір беттен тұратын
теңге/USD конвертерінің жоспарын құр.
Таза HTML/CSS/JS, build қадамы жоқ, бір ғана файл.

Түсініксіз жері болса, алдымен маған сұрақ қой.
Әзірге код жазба.
```
</Prompt>

Жоспарды мақұлдамай тұрып өңде. Жоспардың үш жолын өзгерту diff-тің үш жүз жолын тексеруден әлдеқайда арзан.
</Step>

<Step title="Мақұлда, содан соң diff-ті файлдап тексер">
Cursor әр өзгерген файлды Accept және Reject түймелерімен көрсетеді. Түйменің қайда тұрғанын білу үшін бір рет әдейі Reject бас. Содан кейін `index.html` файлын браузеріңде өзің аш.
</Step>

<Step title="Нұсқаулық файлды жаздыр да, commit жаса">
Былай сұра: «осы жобаны қалай іске қосу керегін және жаңа ғана қолданған код стилімізді жазып, AGENTS.md жаса». Сосын `git add -A && git commit -m "first agent build"` пәрменін орында. Сол файлды төменде қайта қолданасың.
</Step>

<Step title="Қосымша: дәл сол агент терминалда">
Cursor-дың CLI құралы бар, оның бинарлық файлы — `agent`. macOS, Linux және WSL-де `curl https://cursor.com/install -fsS | bash` арқылы, PowerShell-де `irm 'https://cursor.com/install?win32=true' | iex` арқылы орнат, содан соң `agent "explain this repo"` пәрменін іске қос.
</Step>
</Steps>

<Callout type="info" title="Студенттерге арналған тегін жылды іздеп келсең">
Ол жоқ. Cursor-дың [студенттер беті](https://cursor.com/students) енді тек кампустағы және онлайн іс-шаралардағы жеңілдіктерді ғана уәде етеді. Hobby жоспарына немесе төмендегі тегін нұсқалардың біріне бағдарлан.
</Callout>

## Codex CLI: жоспар қадамын өзің сұрап аласың

OpenAI компаниясының агенті бір аккаунтпен терминалда да, IDE кеңейтімінде де, бұлтта да жұмыс істейді. CLI құралы — [Apache-2.0 лицензиясымен, 125,7 мың жұлдыз](https://github.com/openai/codex), 2026 ж. 21 қыркүйектегі дерек. Codex ChatGPT Free ішінде шағын лимитпен, Go жоспарында $8-ге және [Plus жоспарында $20-ға](https://learn.chatgpt.com/docs/pricing) беріледі — ондағы шектер бір сан емес, модельге қарай жылжып отыратын бес сағаттық диапазон түрінде жарияланған.

<Steps>
<Step title="Орнат">
<Terminal title="bash">
```bash
# macOS / Linux
npm install -g @openai/codex
# or
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Terminal>

<Terminal title="PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Terminal>

Пакеттің аты — `@openai/codex`, жай ғана `codex` емес. Осы жолды көшіріп ал, жадыңнан теріп жазба.
</Step>

<Step title="Кір де, промпт жазбас бұрын реттегіштерді қарап шық">
`cd vibe-demo && codex` пәрменін орындап, «Sign in with ChatGPT» тармағын таңда. Осы ретпен үш «/» пәрмені: `/status` модельді, sandbox-ты және мақұлдау параметрін көрсетеді; `/model` модель мен пайымдау күшін таңдайды; `/permissions` сенен сұрамай не істелетінін шешеді. Windows-та [қосымша нұсқаулық](https://www.codeagentswarm.com/en/guides/codex-cli-on-windows) sandbox-ты эксперименттік деп жазады — WSL-ді таңда да, мақұлдауды қосулы қалдыр.
</Step>

<Step title="AGENTS.md файлын жаздыр да, қысқарт">
`/init` пәрмені `AGENTS.md` жазып береді. Оны бірден ашып, айтпаса да түсінікті немесе шындыққа сай келмейтін жолдардың бәрін өшір. Неге қысқасы ұтатынын төмендегі бөлім түсіндіреді.
</Step>

<Step title="Дәл сол конвертерді жаса">
<Prompt title="Жасау промпты" where="Codex CLI · after /init">
```text
AGENTS.md файлында сипатталған теңге/USD конвертерін жаса:
бір HTML файл, бағамы кодтың ішіне жазып қойылған, build қадамы жоқ.

Алдымен жоспарды көрсет те, менің келісімімді күт.
Содан кейін өзгерістерді бір-бірлеп енгіз.
```
</Prompt>

Әр өзгеріс пен пәрменді пайда болған сайын мақұлда. Бетті өзің аш — қорытындыдағы «істеп тұр» деген сөзге сенбе.
</Step>

<Step title="Өз diff-ін өзіне тексерт, сосын көлемін ұлғайт">
`/review` пәрмені Codex-ті әлі commit жасалмаған өзгерістеріңе тексеруші етіп қояды. Тапқанын түзет те, commit жаса. Содан соң кейін керек болатын үш пәрменмен таныс: `codex exec "add a EUR option"` интерактивсіз жұмыс істейді, `codex resume` ескі сеансты қайта ашады, ал `codex cloud` тапсырманы сенікі емес машинаға тапсырады.
</Step>
</Steps>

<Callout type="warn" title="Біреуге тегін аккаунт уәде етпес бұрын мынаны тексер">
Codex-тің README файлындағы кіру туралы азатжолда Plus, Pro, Business, Edu және Enterprise аталады, ал [бағалар беті](https://learn.chatgpt.com/docs/pricing) Codex Free мен Go жоспарларына да кіреді дейді. Екі ресми бет — екі түрлі әңгіме. Воркшопты соның үстіне құрмай тұрып, нағыз тегін аккаунтпен тексеріп ал.
</Callout>

## Gemini CLI енді тегін нұсқа емес

Көп оқулық мұны әлі де қате жазып жүр. 2026 ж. 19 мамырда жетекші әзірлеушілер 18 маусымнан бастап «Gemini CLI will stop serving requests for Google AI Pro and Ultra» деп хабарлады — яғни Gemini CLI Google AI Pro мен Ultra сұрауларын өңдеуді тоқтатады, әрі бұл құралды тегін қолданып жүргендерге де қатысты болды. Тұтынушылар Antigravity CLI құралына көшірілді. Сол жазба [6 «ұнады» белгісіне қарсы 301 «ұнатпадым» жинады](https://github.com/google-gemini/gemini-cli/discussions/27274). Бұл — екінші қысқарту: 2026 ж. 18 наурызда жарияланған [жаңарту](https://github.com/google-gemini/gemini-cli/discussions/22970) Gemini Pro модельдерін бұған дейін-ақ ақылы жазылымның артына жасырып қойған болатын.

Ол әлі де Apache-2.0 лицензиясында және әлі де `npm install -g @google/gemini-cli` пәрменімен орнайды. **Университетіңде не жұмыс орныңда Gemini Code Assist Standard немесе Enterprise болса, я болмаса ақылы кілтің болса** — ол әлі де дұрыс құрал: `gemini` пәрменін іске қос, API кілтін немесе Vertex аутентификациясын таңда, контексті `GEMINI.md` файлында ұста. Ақысыз AI Studio кілті әлі жұмыс істей ме — бұл жайында Google-дың өз беттері бір-біріне қайшы жазады, сондықтан керек болатын күннің алдында тексеріп ал.

<Callout type="danger" title="README — құжаттама емес">
Gemini CLI құралының README файлы күніне 1 000 тегін сұрау деп әлі жарнамалап тұр, ал [құжаттама сайты](https://geminicli.com/docs/resources/quota-and-pricing/) құрал тұтынушылар үшін 2026 ж. 18 маусымда ауыстырылғанын бірнеше ай бұрын жазған. README мен құжаттама беті қайшы келсе, күні қойылғанына сен.
</Callout>

### Оның орнын басқан тегін терминал агенті

Antigravity CLI — сол ауыстырушы, оның бинарлық файлы `agy` деп аталады. Individual жоспары $0 тұрады, апталық шектеулері бар, әрі ол Google-дікі емес модельдерге де қызмет көрсетеді: [бағалар беті](https://antigravity.google/pricing) Gemini 3.8, 3.7 және 3.6 Flash, Gemini 3.1 Pro, Claude Sonnet пен Opus 4.6, сондай-ақ gpt-oss-120b модельдерін тізеді. Қазақстан [қолдау көрсетілетін елдер тізімінде](https://antigravity.google/docs/faq/) бар. Екі қатаң шектеу: тек жеке Google аккаунттары және 18-ге толмағандарға болмайды.

<Steps>
<Step title="Орнат та, іске қос">
<Terminal title="PowerShell">
```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```
</Terminal>

<Terminal title="bash">
```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
cd vibe-demo
agy
```
</Terminal>

Бинарлық файл `~/.local/bin/agy` жолына, Windows-та `C:\Users\<username>\AppData\Local\agy\bin` ішіне түседі. Жол танылуы үшін жаңа терминал аш.
</Step>

<Step title="Алғашқы іске қосу шеберінен өт">
Түс схемасы, көрсету режимі, осы жұмыс кеңістігіне сену, одан соң Google арқылы кіру. Университет Wi-Fi желісінде localhost қайта шақыруы кейде сәтсіз аяқталады; ондай кезде `agy` авторизация URL-ін басып шығара алады.
</Step>

<Step title="Квотаңды жұмсамай тұрып қарап ал">
`/usage` осы аптада әр модель бойынша не қалғанын көрсетеді. Есептеуіші бар кез келген құралда бірінші осыны істе: бюджетіңді біліп отырған оны кездейсоқ ашқаннан артық.
</Step>

<Step title="Өзіңнен сұрақ алдыр, сосын жасат">
`/grill-me` пәрмені агентті бірдеңе жазар алдында нақтылаушы сұрақтар қоюға мәжбүрлейді — осы беттегі тегін талап тексерісіне ең жақын нәрсе.

<Prompt title="Сұрақ жаудыру промпты" where="Antigravity CLI · agy">
```text
/grill-me Бағамы кодтың ішіне жазып қойылған, бір беттен тұратын
теңге/USD конвертерін жаса.
Таза HTML/CSS/JS, build қадамы жоқ, бір ғана файл.

Код жазбас бұрын маған керек сұрақтың бәрін қой.
```
</Prompt>

Шыныңды айт, жасауына мүмкіндік бер, содан соң файлды браузеріңде өзің аш.
</Step>

<Step title="Дербестік реттегішін сезін де, commit жаса">
`/goal <task>` бірде-бір мақұлдау тоқтауынсыз соңына дейін жүгіреді. Оны бір ғана шағын толықтыруда байқап көр, сосын өзіңнен сұра: бұл параметр қай жерден бастап қауіпсіз болудан қалады? `agy` жұмыс каталогындағы `AGENTS.md` файлын оқиды; тек Antigravity-ге қатысты ережелер `.agents/rules/` ішінде жатады.
</Step>
</Steps>

| **Gemini CLI** | бұрынғы терминал ағынының дәл өзі | тек корпоративтік лицензиямен немесе ақылы кілтпен | 2026 ж. 18 маусымнан бері тұтынушыларға ештеңе жоқ |
| **Antigravity `agy`** | сұрақ алу үшін `/grill-me`; тоқтауларды алып тастау үшін `/goal` | қадам сайын, `/goal` таңдамасаң | Individual жоспары, апталық шектеу, **тек 18+** |

Нағыз айырмашылық — тексерудің пішінінде. Графикалық diff-ті көзбен жүгіртіп шығу оңай, әрі оқыған болып қою да сондай оңай; терминалдағы агент бір өзгерісті бір рет көрсетеді — баяуырақ, бірақ елемеу қиынырақ. Бірі екіншісінен жақсы емес. Өзіңді қайсысында алдауға бейім екеніңді біл.

## Бәрі оқитын бір нұсқаулық файл

Репозиторий түбіндегі `AGENTS.md` — ортақ стандарт: кәдімгі Markdown, міндетті өрістер жоқ, ішкі қалталарда көшірмелері болуына болады, ең жақыны басым саналады. Оны Linux Foundation құрамындағы Agentic AI Foundation жүргізеді, әрі оны [60 мыңнан астам ашық бастапқы кодты жоба](https://agents.md/) қолданады.

| Файл | Оны кім оқиды | Көбі байқамай қалатын нәрсе |
|---|---|---|
| `AGENTS.md` | Codex, Cursor, Copilot, Jules, opencode, Devin, Aider, `agy`, сондай-ақ 2026 ж. 18 қыркүйектен бері Claude Code | ішкі файлдар ең жақыннан бастап біріктіріледі, сондықтан пакет деңгейіндегі файл басым болады |
| `CLAUDE.md` | Claude Code; сондай-ақ VS Code Copilot — онда `chat.useClaudeMdFile` әдепкіде қосулы | Claude `AGENTS.md` файлын **тек** CLAUDE.md жоқ болғанда ғана оқиды |
| `.cursor/rules/*.mdc` | тек Cursor | frontmatter ішінде `description`, `globs`, `alwaysApply` — ортақ фактілерге емес, glob бойынша шектелген ережелерге арналған |
| `.github/copilot-instructions.md` | Copilot чаты, тексерісі және агенттері | VS Code тапқан нұсқаулық файлдың бәрін біріктіреді, реті кепілдендірілмейді |
| `.agents/rules/` | Antigravity IDE редакторы, жұмыс үстелі қолданбасы және `agy` | `agy` бұған қоса `GEMINI.md` файлын да оқиды |

Рецепт қысқа. Ортақ фактілер `AGENTS.md` ішіне түседі: build, тест және lint жүргізудің нақты пәрмендері, стиль, тиіспеуге тиіс жерлер, commit хабарының ережесі. Claude Code үшін не `CLAUDE.md` файлын өшір, не оны екі жолға түсір — `@AGENTS.md`, плюс Claude-қа қатысты ескертпелерге арналған бір тақырып. [Anthropic құжаттамасы](https://code.claude.com/docs/en/memory) командада Windows қолданатын адам болса, symlink емес, осы импортты ұсынады: symlink-ке әкімші құқығы не Developer Mode керек, әрі git сілтемені кәдімгі мәтін етіп жазып қоюы мүмкін. Сосын тоқта: дәл сол мәтінді `.github/copilot-instructions.md` ішіне де көшірсең, VS Code екеуін де біріктіреді де, сол токендерге екі рет төлейсің.
