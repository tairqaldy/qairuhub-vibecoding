## Бір қалта, бір commit, бір тапсырма

<Terminal title="bash">
```bash
mkdir vibe-demo
cd vibe-demo
git init
git commit --allow-empty -m "empty start"
```
</Terminal>

Әр құралдағы тапсырма біреу: бағамы кодтың ішіне жазып қойылған, бір беттен тұратын теңге/USD конвертері. Таза HTML/CSS/JS, build қадамы жоқ. Бес минуттық жұмыс, бірақ нашар жоспар бірден көрінеді.

<Callout type="warn" title="Осы практикумның басты ережесі">
Әр ірі промпттың алдында commit жаса. Бір қалтада бір күнде үш агент жүгірсе, ұнаған жұмысыңнан оңай айырыласың. `git` — олардың бәрінде бірдей істейтін жалғыз «кері қайтару» түймесі ([09-модуль](/kk/learn/git-and-github/)).
</Callout>

## Cursor: жоспарлау қадамы — пернелер тіркесімі

Ішіне агент салынған VS Code fork-ы, [2026 ж. 14 тамыздан бері](https://cursor.com/blog) SpaceX-ке тиесілі. Hobby жоспарына карта керек емес; [Cursor-дың өз баға құжаттамасы](https://cursor.com/docs/account/pricing) агентті күнде қолданатындардың шығынын айына $20 тұратын Pro жоспарының үстіне $60–$100 деп есептейді. [Бағалар беті](https://cursor.com/pricing) енді Claude мен GPT-мен қатар Grok-ты да тізеді.

<Steps>
<Step title="Орнат та, қалтаны аш">
[cursor.com](https://cursor.com) сайтынан жүктеп ал, Google немесе GitHub арқылы кір, содан соң File → Open Folder → `vibe-demo`.
</Step>

<Step title="Агентті ашып, оны Plan режиміне ауыстыр">
`Ctrl+I` (macOS-та `Cmd+I`) агентті ашады. Енгізу өрісінде `Shift+Tab` Plan режиміне ауыстырады — Claude Code-тағы plan mode-тың дәл өзі ([07-модуль](/kk/learn/the-agent/)). Ол файл емес, жоспар жазады.

<Prompt title="Жоспар промпты" where="Cursor · agent input, Plan mode (Shift+Tab)">
```text
Бағамы кодтың ішіне жазып қойылған, бір беттен тұратын
теңге/USD конвертерінің жоспарын құр.
Таза HTML/CSS/JS, build қадамы жоқ, бір ғана файл.

Түсініксіз жері болса, алдымен маған сұрақ қой.
Әзірге код жазба.
```
</Prompt>

Жоспарды мақұлдамай тұрып өңде. Жоспардың үш жолы diff-тің үш жүз жолынан әлдеқайда арзан.
</Step>

<Step title="Мақұлда, содан соң diff-ті файлдап тексер">
Cursor әр өзгерген файлды Accept және Reject түймелерімен көрсетеді. Түйменің қайда тұрғанын білу үшін бір рет әдейі Reject бас. Сосын `index.html` файлын өзің аш.
</Step>

<Step title="Нұсқаулық файлды жаздыр да, commit жаса">
Былай сұра: «осы жобаны қалай іске қосу керегін және жаңа ғана қолданған код стилімізді жазып, AGENTS.md жаса». Сосын `git add -A && git commit -m "first agent build"` пәрменін орында.
</Step>

<Step title="Қосымша: дәл сол агент терминалда">
Cursor-дың CLI құралы бар, бинарлық файлы — `agent`. macOS, Linux және WSL-де `curl https://cursor.com/install -fsS | bash` арқылы, PowerShell-де `irm 'https://cursor.com/install?win32=true' | iex` арқылы орнат, сосын `agent "explain this repo"` пәрменін іске қос.
</Step>
</Steps>

<Callout type="info" title="Студенттерге арналған тегін жылды іздеп келсең">
Ол жоқ. Cursor-дың [студенттер беті](https://cursor.com/students) енді тек кампустағы және онлайн іс-шаралардағы жеңілдіктерді уәде етеді. Hobby жоспарына немесе төмендегі тегін нұсқаға бағдарлан.
</Callout>

## Codex CLI: жоспар қадамын өзің сұрап аласың

OpenAI агенті бір аккаунтпен терминалда да, IDE кеңейтімінде де, бұлтта да жұмыс істейді. CLI құралы — [Apache-2.0 лицензиясымен, 125,7 мың жұлдыз](https://github.com/openai/codex), 2026 ж. 21 қыркүйектегі дерек. Жоспарлары [07-модульде](/kk/learn/the-agent/); мұндағы маңыздысы — жарияланған [шектер](https://learn.chatgpt.com/docs/pricing) бір сан емес, модельге қарай жылжитын бес сағаттық диапазон.

<Steps>
<Step title="Орнат">
<Terminal title="bash">
```bash
# macOS / Linux
npm install -g @openai/codex
# or
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Terminal>

<Terminal title="PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Terminal>

Пакеттің аты — `@openai/codex`, жай ғана `codex` емес. Осы жолды көшіріп ал, жадыңнан теріп жазба.
</Step>

<Step title="Кір де, промпт жазбас бұрын реттегіштерді қарап шық">
`cd vibe-demo && codex` пәрменін орындап, «Sign in with ChatGPT» тармағын таңда. Сосын осы ретпен үш пәрмен. `/status` модельді, sandbox-ты және мақұлдау параметрін көрсетеді. `/model` модель мен пайымдау күшін таңдайды. `/permissions` сұраусыз не істелетінін шешеді. Windows-та [қосымша нұсқаулық](https://www.codeagentswarm.com/en/guides/codex-cli-on-windows) sandbox-ты эксперименттік деп жазады — WSL-ді таңда, мақұлдауды қосулы қалдыр.
</Step>

<Step title="AGENTS.md файлын жаздыр да, қысқарт">
`/init` пәрмені `AGENTS.md` жазып береді. Оны ашып, айтпаса да түсінікті немесе шындыққа сай емес жолдарды өшір.
</Step>

<Step title="Дәл сол конвертерді жаса">
<Prompt title="Жасау промпты" where="Codex CLI · after /init">
```text
AGENTS.md файлында сипатталған теңге/USD конвертерін жаса:
бір HTML файл, бағамы кодтың ішіне жазып қойылған, build қадамы жоқ.

Алдымен жоспарды көрсет те, менің келісімімді күт.
Содан кейін өзгерістерді бір-бірлеп енгіз.
```
</Prompt>

Әр өзгеріс пен пәрменді пайда болған сайын мақұлда. Бетті өзің аш: қорытынды — дәлел емес.
</Step>

<Step title="Өз diff-ін өзіне тексерт, сосын көлемін ұлғайт">
`/review` пәрмені Codex-ке commit жасалмаған өзгерістеріңді тексертеді. Тапқанын түзет те, commit жаса. Кейін керек болатын үш пәрмен: `codex exec "add a EUR option"` интерактивсіз жұмыс істейді, `codex resume` ескі сеансты қайта ашады, ал `codex cloud` тапсырманы сенікі емес машинаға береді.
</Step>
</Steps>

<Callout type="warn" title="Біреуге тегін аккаунт уәде етпес бұрын мынаны тексер">
Codex README-індегі кіру азатжолы Plus, Pro, Business, Edu және Enterprise дейді; [бағалар беті](https://learn.chatgpt.com/docs/pricing) Codex Free мен Go жоспарларына да кіреді дейді. Екі ресми бет — екі түрлі әңгіме. Воркшопты соның үстіне құрмай тұрып, нағыз тегін аккаунтпен тексер.
</Callout>

## Gemini CLI енді тегін нұсқа емес

2026 ж. 19 мамырда әзірлеушілер 18 маусымнан бастап «Gemini CLI will stop serving requests for Google AI Pro and Ultra» деп хабарлады — яғни Google AI Pro мен Ultra сұрауларын өңдеу тоқтады, тегін қолданып жүргендерге де. Сол жазба [6 «ұнады» белгісіне қарсы 301 «ұнатпадым» жинады](https://github.com/google-gemini/gemini-cli/discussions/27274). Бұл — екінші қысқарту: 2026 ж. 18 наурыздағы [жаңарту](https://github.com/google-gemini/gemini-cli/discussions/22970) Gemini Pro модельдерін бұған дейін-ақ ақылы жазылымның артына жасырып қойған.

Ол әлі де Apache-2.0 лицензиясында, әлі де `npm install -g @google/gemini-cli` пәрменімен орнайды. **Университетіңде не жұмыс орныңда Gemini Code Assist Standard немесе Enterprise болса, я ақылы кілтің болса** — әлі де дұрыс құрал: `gemini` пәрменін іске қос, API кілтін немесе Vertex аутентификациясын таңда, контексті `GEMINI.md` ішінде ұста. Ақысыз AI Studio кілті туралы Google беттері бір-біріне қайшы жазады, сондықтан керек күннің алдында тексер.

<Callout type="danger" title="README — құжаттама емес">
Gemini CLI README-і күніне 1 000 тегін сұрау деп әлі жарнамалайды, ал [құжаттама сайты](https://geminicli.com/docs/resources/quota-and-pricing/) құрал тұтынушылар үшін 2026 ж. 18 маусымда ауыстырылғанын бірнеше ай бұрын жазған. README мен құжаттама беті қайшы келсе, күні қойылғанына сен.
</Callout>

### Оның орнын басқан тегін терминал агенті

Antigravity CLI — сол ауыстырушы. Бинарлық файлы — `agy`. Individual жоспары $0 тұрады, апталық шектеулері бар, әрі ол Google-дікі емес модельдерге де қызмет көрсетеді: [бағалар беті](https://antigravity.google/pricing) Gemini 3.8, 3.7 және 3.6 Flash, Gemini 3.1 Pro, Claude Sonnet пен Opus 4.6, сондай-ақ gpt-oss-120b модельдерін тізеді. Қазақстан [қолдау көрсетілетін елдер тізімінде](https://antigravity.google/docs/faq/) бар. Екі қатаң шектеу: тек жеке Google аккаунттары, 18-ге толмағандарға болмайды.

<Steps>
<Step title="Орнат та, іске қос">
<Terminal title="PowerShell">
```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```
</Terminal>

<Terminal title="bash">
```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
cd vibe-demo
agy
```
</Terminal>

Бинарлық файл `~/.local/bin/agy` жолына, Windows-та `C:\Users\<username>\AppData\Local\agy\bin` ішіне түседі. Жол танылуы үшін жаңа терминал аш.
</Step>

<Step title="Алғашқы іске қосу шеберінен өт">
Түс схемасы, көрсету режимі, осы жұмыс кеңістігіне сену, одан соң Google арқылы кіру. Университет Wi-Fi желісінде localhost қайта шақыруы кейде сәтсіз аяқталады. Ондай кезде `agy` авторизация URL-ін басып шығарады.
</Step>

<Step title="Квотаңды жұмсамай тұрып қарап ал">
`/usage` осы аптада әр модель бойынша не қалғанын көрсетеді. Есептеуіші бар кез келген құралда бірінші осыны істе.
</Step>

<Step title="Өзіңнен сұрақ алдыр, сосын жасат">
`/grill-me` пәрмені агентті код жазбас бұрын нақтылаушы сұрақтар қоюға мәжбүрлейді.

<Prompt title="Сұрақ жаудыру промпты" where="Antigravity CLI · agy">
```text
/grill-me Бағамы кодтың ішіне жазып қойылған, бір беттен тұратын
теңге/USD конвертерін жаса.
Таза HTML/CSS/JS, build қадамы жоқ, бір ғана файл.

Код жазбас бұрын маған керек сұрақтың бәрін қой.
```
</Prompt>

Шыныңды айт, жасауына мүмкіндік бер, сосын файлды өзің аш.
</Step>

<Step title="Дербестік реттегішін сезін де, commit жаса">
`/goal <task>` бірде-бір мақұлдау тоқтауынсыз соңына дейін жүгіреді. Бір ғана шағын толықтыруда байқап көр, сосын сұра: бұл параметр қай жерден бастап қауіпсіз болудан қалады? `agy` жұмыс каталогындағы `AGENTS.md` файлын оқиды. Тек Antigravity ережелері `.agents/rules/` ішінде жатады.
</Step>
</Steps>

## Бір тапсырма, бес құрал, бес түрлі кедергі

| Құрал | Жоспарлау қадамы қай жерде | Нені мақұлдайсың | $0-ға не тиеді |
|---|---|---|---|
| **Claude Code** | `Shift+Tab` — plan mode-қа өту | алдымен жоспарды, сосын рұқсат режиміне қарай өзгерістерді | мұнда $0 жолы жоқ; курс Claude Pro бар деп есептейді |
| **Cursor** | агент өрісінде `Shift+Tab` | графикалық терезеде әр файлдың diff-ін Accept/Reject | Hobby, агент сұраулары шектеулі, карта керек емес |
| **Codex CLI** | промптта өзің сұрайсың; қалғанын `/permissions` шешеді | әр өзгеріс пен пәрменді пайда болған сайын | ChatGPT Free ішіндегі шағын лимит |
| **Gemini CLI** | бұрынғы терминал ағынының дәл өзі | тек корпоративтік лицензиямен немесе ақылы кілтпен | 2026 ж. 18 маусымнан бері тұтынушыларға ештеңе жоқ |
| **Antigravity `agy`** | сұрақ алу үшін `/grill-me`; тоқтауларды алып тастау үшін `/goal` | қадам сайын, `/goal` таңдамасаң | Individual жоспары, апталық шектеу, **тек 18+** |

Графикалық diff-ті көзбен жүгіртіп шығу оңай, оқыған болып қою да сондай оңай; терминалдағы агент бір өзгерісті бір рет көрсетеді. Өзіңді қайсысында алдауға бейім екеніңді біл.

## Бәрі оқитын бір нұсқаулық файл

Репозиторий түбіндегі `AGENTS.md` — ортақ стандарт, ал оның ішіне не жазылатыны [06-модульде](/kk/learn/context-ssot/). Құралдан құралға өзгеретіні — оны кім оқиды әрі олар тағы нені оқиды.

| Файл | Оны кім оқиды | Көбі байқамай қалатын нәрсе |
|---|---|---|
| `AGENTS.md` | Codex, Cursor, Copilot, Jules, opencode, Devin, Aider, `agy`, сондай-ақ 2026 ж. 18 қыркүйектен бері Claude Code | ішкі файлдар ең жақыннан бастап біріктіріледі, сондықтан пакет деңгейіндегі файл басым болады |
| `CLAUDE.md` | Claude Code; сондай-ақ VS Code Copilot — онда `chat.useClaudeMdFile` әдепкіде қосулы | Claude `AGENTS.md` файлын **тек** CLAUDE.md жоқ болғанда ғана оқиды |
| `.cursor/rules/*.mdc` | тек Cursor | frontmatter ішінде `description`, `globs`, `alwaysApply` — ортақ фактілерге емес, glob бойынша шектелген ережелерге арналған |
| `.github/copilot-instructions.md` | Copilot чаты, тексерісі және агенттері | VS Code тапқан нұсқаулық файлдың бәрін біріктіреді, реті кепілдендірілмейді |
| `.agents/rules/` | Antigravity IDE редакторы, жұмыс үстелі қолданбасы және `agy` | `agy` бұған қоса `GEMINI.md` файлын да оқиды |

Ортақ фактілер `AGENTS.md` ішіне түседі, ал пішінін төмендегі промпт көрсетеді. Claude Code үшін `CLAUDE.md` файлын `@AGENTS.md` пен Claude-қа ғана қатысты ескертпелерге дейін қысқарт. [Anthropic құжаттамасы](https://code.claude.com/docs/en/memory) symlink орнына осы импортты ұсынады: Windows-та symlink-ке әкімші құқығы не Developer Mode керек, әрі git оны кәдімгі мәтін етіп жазып қоюы мүмкін. Сосын тоқта. Дәл сол мәтінді `.github/copilot-instructions.md` ішіне де көшірсең, VS Code екеуін біріктіреді де, сол токендерге екі рет төлейсің.
